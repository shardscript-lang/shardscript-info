<H2>Summary</H2>

<Prose>
  ShardScript provides imperative looping constructs for repeating a block of
  code while a condition holds, scanning a sequence, or counting with a
  C-style initializer/condition/step header. The language supports{' '}
  <InlineCode>while</InlineCode>, <InlineCode>until</InlineCode>, C-style{' '}
  <InlineCode>for</InlineCode>, <InlineCode>foreach</InlineCode>, integer range
  expressions, and the <InlineCode>break</InlineCode> /{' '}
  <InlineCode>continue</InlineCode> jump statements.
</Prose>

<H2>Syntax</H2>

<Prose>
  Every loop body is a statement block enclosed in braces. Conditions are
  written inside parentheses.
</Prose>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <InlineCode>while (condition) &#123; body &#125;</InlineCode>
  </Bullet>
  <Bullet>
    <InlineCode>until (condition) &#123; body &#125;</InlineCode>
  </Bullet>
  <Bullet>
    <InlineCode>for (initializer; condition; step) &#123; body &#125;</InlineCode>
  </Bullet>
  <Bullet>
    <InlineCode>foreach (identifier in enumerable) &#123; body &#125;</InlineCode>
  </Bullet>
  <Bullet>
    Half-open range: <InlineCode>lower..upper</InlineCode>
  </Bullet>
  <Bullet>
    Inclusive range: <InlineCode>lower..&amp;upper</InlineCode>
  </Bullet>
  <Bullet>
    <InlineCode>break;</InlineCode> and <InlineCode>continue;</InlineCode>
  </Bullet>
</ul>

<Prose>
  The condition for <InlineCode>while</InlineCode> and{' '}
  <InlineCode>until</InlineCode> must evaluate to <InlineCode>bool</InlineCode>.
  The C-style <InlineCode>for</InlineCode> header contains three statements
  separated by semicolons: an initializer that runs once, a condition checked
  before every iteration, and a step expression run after the body. A{' '}
  <InlineCode>foreach</InlineCode> loop declares an iteration variable that is
  scoped to the body and binds successive elements from any{' '}
  <InlineCode>IEnumerable&lt;T&gt;</InlineCode> source.
</Prose>

<Prose>
  Range expressions are first-class expressions that produce an{' '}
  <InlineCode>int[]</InlineCode>. They can be assigned to a variable, passed to a
  function, or used directly inside <InlineCode>foreach</InlineCode>.
</Prose>

<H2>Returns</H2>

<Prose>
  Loop statements do not produce a value. A range expression evaluates to an
  array of integers (<InlineCode>int[]</InlineCode>). <InlineCode>break</InlineCode>{' '}
  and <InlineCode>continue</InlineCode> are control-flow statements and also
  produce no value.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Non-bool condition</strong> —{' '}
    <InlineCode>while</InlineCode>, <InlineCode>until</InlineCode>, and C-style{' '}
    <InlineCode>for</InlineCode> conditions must be boolean expressions.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Invalid range bounds</strong> — Both
    sides of <InlineCode>..</InlineCode> and <InlineCode>..&amp;</InlineCode> must
    be <InlineCode>int</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">foreach source not enumerable</strong> —{' '}
    <InlineCode>foreach</InlineCode> requires a type that implements{' '}
    <InlineCode>IEnumerable&lt;T&gt;</InlineCode>. Plain object references or
    unrelated types are rejected at compile time.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">break / continue outside a loop</strong> —{' '}
    Both statements must appear lexically inside a loop body.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Keyword statement in for header</strong> —{' '}
    <InlineCode>if</InlineCode>, <InlineCode>while</InlineCode>,{' '}
    <InlineCode>foreach</InlineCode>, and similar keyword statements cannot be
    used as the initializer or step of a C-style <InlineCode>for</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Division / modulo by zero</strong> — Any
    arithmetic in a loop condition or step that divides or modulos by zero throws
    at runtime.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>Range semantics.</strong> A range expression allocates a new{' '}
  <InlineCode>int[]</InlineCode> containing every integer between the bounds.
  <InlineCode>lower..upper</InlineCode> is half-open: it includes{' '}
  <InlineCode>lower</InlineCode> and excludes <InlineCode>upper</InlineCode>.
  <InlineCode>lower..&amp;upper</InlineCode> is inclusive and also includes the
  upper bound. If <InlineCode>upper</InlineCode> is smaller than{' '}
  <InlineCode>lower</InlineCode>, the array counts downward. Equal bounds yield an
  empty array for the half-open operator and a single-element array for the
  inclusive operator.
</Prose>

<Prose>
  <strong>foreach implementation.</strong> The compiler lowers{' '}
  <InlineCode>foreach</InlineCode> to an enumerator pattern: it calls{' '}
  <InlineCode>GetEnumerator()</InlineCode>, then repeatedly calls{' '}
  <InlineCode>MoveNext()</InlineCode> and reads <InlineCode>Current</InlineCode>{' '}
  until the enumerator reports no more items. This works for arrays, lists,
  dictionaries, and any user-defined type that implements{' '}
  <InlineCode>IEnumerable&lt;T&gt;</InlineCode>.
</Prose>

<Callout tone="blue">
  Arrays are also <InlineCode>IEnumerable&lt;T&gt;</InlineCode>, so{' '}
  <InlineCode>foreach</InlineCode> accepts both ranges and array literals
  directly.
</Callout>

<Prose>
  <strong>Legacy for-in syntax.</strong> ShardScript still recognizes{' '}
  <InlineCode>for (x in ...)</InlineCode> as an older alias, but the compiler
  restricts it to array sources. New code should prefer{' '}
  <InlineCode>foreach</InlineCode> because it accepts any enumerable source and
  matches the standard library pattern.
</Prose>

<Prose>
  <strong>break, continue, and defer.</strong>{' '}
  <InlineCode>break</InlineCode> exits the innermost enclosing loop and runs any
  deferred statements owned by scopes that are being left.{' '}
  <InlineCode>continue</InlineCode> jumps to the end of the current loop body,
  which is <em>before</em> the step expression in a C-style{' '}
  <InlineCode>for</InlineCode>. Deferred statements inside the loop body are not
  executed by <InlineCode>continue</InlineCode>; if cleanup is required, use an
  explicit guard or restructure the loop.
</Prose>

<Prose>
  <strong>Infinite loops.</strong> A <InlineCode>while (true)</InlineCode> loop
  with no <InlineCode>break</InlineCode>, <InlineCode>return</InlineCode>, or
  throwing path will run forever. The VM does not currently detect or abort such
  loops.
</Prose>

<Callout tone="amber" title="Compound assignment in loop steps">
  Compound assignment operators such as <InlineCode>+=</InlineCode> and{' '}
  <InlineCode>-=</InlineCode> are parsed but currently lowered as plain
  assignments by the VM. Until that is fixed, write the step explicitly — for
  example, <InlineCode>i = i + 1</InlineCode> instead of{' '}
  <InlineCode>i += 1</InlineCode>.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>while and until.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public static func Main() -> void
{
    counter: int = 0;

    // Run while the condition is true.
    while (counter < 3)
    {
        println(counter);            // 0, 1, 2
        counter = counter + 1;
    }

    // until runs while its condition is false.
    countdown: int = 3;
    until (countdown == 0)
    {
        println(countdown);          // 3, 2, 1
        countdown = countdown - 1;
    }
}`}
  language="csharp"
  filename="while_until.shard"
/>

<Prose>
  <strong>C-style for with ascending and descending steps.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public static func Main() -> void
{
    // initializer; condition; step
    for (i: int = 0; i < 5; i = i + 1)
    {
        print(i);
        print(" ");
    }
    println("");                     // 0 1 2 3 4

    // Descending step must be written explicitly; there is no automatic stride.
    for (i: int = 10; i > 0; i = i - 2)
    {
        print(i);
        print(" ");
    }
    println("");                     // 10 8 6 4 2
}`}
  language="csharp"
  filename="cstyle_for.shard"
/>

<Prose>
  <strong>Half-open, inclusive, and reverse ranges.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public static func Main() -> void
{
    // 0..3 is half-open: includes 0, 1, 2.
    half: int[] = 0..3;
    println(half.Length);            // 3

    // 0..&3 is inclusive: includes 0, 1, 2, 3.
    full: int[] = 0..&3;
    println(full.Length);            // 4

    // Reverse range counts down.
    down: int[] = 3..0;
    foreach (n in down)
    {
        println(n);                  // 3, 2, 1
    }

    // Edge cases with equal bounds.
    println((5..5).Length);          // 0
    println((5..&5).Length);         // 1
}`}
  language="csharp"
  filename="ranges.shard"
/>

<Prose>
  <strong>foreach over arrays, ranges, and collections.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using collections;

namespace demo;

public static func Main() -> void
{
    // Array literal.
    nums: int[] = [10, 20, 30];
    foreach (n in nums)
    {
        println(n);
    }

    // Range expression.
    foreach (i in 1..5)
    {
        print(i);
        print(" ");
    }
    println("");                     // 1 2 3 4

    // List<T> implements IEnumerable<T>.
    list: List<int> = new List<int>();
    list.Add(100);
    list.Add(200);
    foreach (value in list)
    {
        println(value);
    }
}`}
  language="csharp"
  filename="foreach.shard"
/>

<Prose>
  <strong>break and continue.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public static func Main() -> void
{
    foreach (i in 0..10)
    {
        if (i == 5)
        {
            break;                   // exit the loop entirely
        }

        if (i % 2 == 0)
        {
            continue;                // skip to the next iteration
        }

        println(i);                  // 1, 3
    }
}`}
  language="csharp"
  filename="break_continue.shard"
/>

<Prose>
  <strong>Nested loops and early exit.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public static func Main() -> void
{
    // Find the first pair whose product is divisible by 7.
    found: bool = false;

    foreach (a in 2..6)
    {
        foreach (b in 2..6)
        {
            product: int = a * b;
            if (product % 7 == 0)
            {
                println("a=" + a + " b=" + b + " product=" + product);
                found = true;
                break;               // exits only the inner foreach
            }
        }

        if (found)
        {
            break;                   // exits the outer foreach
        }
    }
}`}
  language="csharp"
  filename="nested_loops.shard"
/>

<Prose>
  <strong>Common mistakes to avoid.</strong>
</Prose>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    Writing <InlineCode>i += 1</InlineCode> in a C-style{' '}
    <InlineCode>for</InlineCode> step currently behaves like a plain assignment.
    Use <InlineCode>i = i + 1</InlineCode>.
  </Bullet>
  <Bullet>
    Using <InlineCode>break</InlineCode> or <InlineCode>continue</InlineCode>
    outside any loop is a compile-time error.
  </Bullet>
  <Bullet>
    <InlineCode>foreach</InlineCode> variables are read-only in the sense that
    rebinding the iteration variable inside the body does not affect the source
    collection; it only shadows the loop variable.
  </Bullet>
  <Bullet>
    Ranges allocate a temporary array. For very large sequences, consider a
    C-style <InlineCode>for</InlineCode> loop to avoid the allocation.
  </Bullet>
</ul>
