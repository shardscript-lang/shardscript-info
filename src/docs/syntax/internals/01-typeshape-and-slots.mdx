<H2>Summary</H2>

<Prose>
  A <InlineCode>TypeShape</InlineCode> is the runtime memory-layout descriptor that the compiler
  generates for every class, struct, array, and closed generic type. It maps each instance field to
  a numbered <InlineCode>SlotIndex</InlineCode> at a fixed byte <InlineCode>Offset</InlineCode>,
  turning field access into constant-time pointer arithmetic and giving every generic instantiation
  a concrete, non-erased layout.
</Prose>

<H2>Syntax</H2>

<Prose>
  <InlineCode>TypeShape</InlineCode> is not constructed from ShardScript source. It is produced
  automatically by the compiler&apos;s <InlineCode>LayoutGenerator</InlineCode> and cached by the
  runtime&apos;s <InlineCode>TypeShapeCache</InlineCode>. The resulting descriptor has the following
  public structure inside the VM:
</Prose>

<CodeBlock
  code={`class TypeShape
{
public:
    TypeSymbol* BaseType;                      // the type this shape describes
    std::vector<TypeSymbol*> GenericArguments; // concrete args for a closed generic
    std::size_t Size;                          // total inline size in bytes

    struct SlotInfo
    {
        std::size_t Offset;                    // byte offset inside the instance
        TypeShape* FieldShape;                 // layout descriptor of the field's type
    };

    std::vector<SlotInfo> Slots;               // one entry per instance field slot
};`}
  language="cpp"
  filename="typeshape.hpp"
/>

<Prose>
  Each <InlineCode>FieldSymbol</InlineCode> carries the slot metadata that the compiler bakes into
  bytecode:
</Prose>

<H2>Parameters / Arguments</H2>

<Prose>
  The layout generator takes the semantic model and produces one shape for every type that has
  instance fields. The shape is parameterised by:
</Prose>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">BaseType</strong> — the <InlineCode>TypeSymbol</InlineCode>
    {' '}being laid out. For <InlineCode>Container&lt;int&gt;</InlineCode> this is the generic
    container type; for <InlineCode>Point</InlineCode> it is the struct type itself.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">GenericArguments</strong> — the concrete type arguments
    {' '}that substitute the type parameters when the shape describes a closed generic instantiation.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Fields</strong> — every non-static instance field declared
    {' '}on the type, in declaration order. Static fields live outside instance memory and do not
    {' '}receive slots.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Inlining mode</strong> — value types
    {' '}(<InlineCode>ByValue</InlineCode>) are embedded inline; reference types
    {' '}(<InlineCode>ByReference</InlineCode>) occupy a pointer-sized slot and point at a separate
    {' '}heap object.
  </Bullet>
</ul>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Recursive struct inlining</strong> — A struct that contains
    {' '}itself directly or transitively by value causes a compile-time error from
    {' '}<InlineCode>LayoutGenerator::FixObjectLayout</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Slot index out of range</strong> — Calling
    {' '}<InlineCode>TypeShape::GetOffset(slot)</InlineCode> or
    {' '}<InlineCode>GetFieldShape(slot)</InlineCode> with a slot greater than or equal to
    {' '}<InlineCode>Slots.size()</InlineCode> throws <InlineCode>std::out_of_range</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Type not found</strong> —
    {' '}<InlineCode>Type.GetType(name)</InlineCode> throws a runtime exception when no type with the
    {' '}given name or full name exists in the symbol table.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Null reflection target</strong> —
    {' '}<InlineCode>Type.Of(null)</InlineCode> returns the null instance rather than a
    {' '}<InlineCode>Type</InlineCode> object.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>Layout pass.</strong> After semantic analysis, <InlineCode>LayoutGenerator::Generate</InlineCode>
  {' '}walks every type in the symbol table. For each non-static instance field it assigns the next
  {' '}available <InlineCode>SlotIndex</InlineCode> and records the current
  {' '}<InlineCode>MemoryBytesOffset</InlineCode>. The running offset is advanced by the inline size
  {' '}of the field type, which is itself laid out recursively before the containing type.
</Prose>

<Prose>
  <strong>Value types versus reference types.</strong> A field whose type is a value type
  {' '}(<InlineCode>int</InlineCode>, <InlineCode>double</InlineCode>, <InlineCode>bool</InlineCode>,
  {' '}<InlineCode>char</InlineCode>, <InlineCode>byte</InlineCode>, or a
  {' '}<InlineCode>struct</InlineCode>) is stored inline at its offset. A field whose type is a
  {' '}reference type (<InlineCode>class</InlineCode>, <InlineCode>string</InlineCode>, array) stores
  {' '}only an <InlineCode>ObjectInstance*</InlineCode> pointer at the offset; the actual object lives
  {' '}elsewhere on the GC heap. This distinction is recorded in the type symbol&apos;s
  {' '}<InlineCode>TypeInlining</InlineCode> flag.
</Prose>

<Prose>
  <strong>ObjectInstance layout.</strong> Every object is a small header plus a raw memory block of
  {' '}<InlineCode>TypeShape::Size</InlineCode> bytes. The header keeps a pointer to the
  {' '}<InlineCode>TypeSymbol</InlineCode>, a pointer to the <InlineCode>TypeShape</InlineCode>, a
  {' '}reference count, and VM bookkeeping flags. Field access is therefore:
</Prose>

<CodeBlock
  code={`// VM field read for a reference-type field.
// 'slot' is a compile-time constant taken from the FieldSymbol.
ObjectInstance* ObjectInstance::GetField(std::uint32_t slot)
{
    std::size_t offset = m_shape->GetOffset(slot);       // slot -> byte offset
    void* address = OffsetMemory(offset, sizeof(ObjectInstance*));
    return *static_cast<ObjectInstance**>(address);      // read the pointer
}`}
  language="cpp"
  filename="objectinstance_getfield.cpp"
/>

<Callout tone="blue">
  No hash table is consulted on the hot path. Field access is <InlineCode>O(1)</InlineCode>{' '}
  pointer arithmetic over contiguous memory. The only map is the <InlineCode>TypeShapeCache</InlineCode>,
  {' '}which is consulted once per closed generic instantiation.
</Callout>

<Prose>
  <strong>Reified generics.</strong> ShardScript generics are reified, not erased. Each closed
  {' '}instantiation receives its own <InlineCode>TypeShape</InlineCode> keyed by
  {' '}(<InlineCode>base type</InlineCode>, <InlineCode>generic arguments</InlineCode>). When
  {' '}<InlineCode>TypeShapeCache::BuildShape</InlineCode> constructs the shape, it substitutes the
  {' '}type parameters into every field and recomputes offsets and total size. Two
  {' '}<InlineCode>Container&lt;int&gt;</InlineCode> instances share one shape;
  {' '}<InlineCode>Container&lt;int&gt;</InlineCode> and <InlineCode>Container&lt;string&gt;</InlineCode>
  {' '}have distinct shapes.
</Prose>

<Prose>
  <strong>Static fields.</strong> Static fields are omitted from the instance shape. They are
  {' '}allocated once per type and accessed by symbol resolution rather than by slot index. A
  {' '}<InlineCode>TypeShape</InlineCode> describes only instance layout.
</Prose>

<Prose>
  <strong>Arrays.</strong> Array shapes are a special case. The shape size is
  {' '}<InlineCode>Array header size + elementShape->Size * Length</InlineCode>. The elements are
  {' '}stored inline after the array header, and element access uses the element shape to compute
  {' '}offsets.
</Prose>

<Prose>
  <strong>Reflection integration.</strong> The <InlineCode>shard.reflection</InlineCode> library wraps
  {' '}the same compiler symbols. <InlineCode>Type.Of(instance)</InlineCode> reads
  {' '}<InlineCode>instance->getInfo()</InlineCode>; <InlineCode>Type.GetFields()</InlineCode> returns
  {' '}<InlineCode>FieldInfo</InlineCode> objects backed by the same <InlineCode>FieldSymbol</InlineCode>
  {' '}records that carry the slot index and byte offset. The <InlineCode>Type</InlineCode> class itself
  {' '}is a normal class with its own <InlineCode>TypeShape</InlineCode>, so reflection on a
  {' '}<InlineCode>Type</InlineCode> instance is laid out exactly like any other object.
</Prose>

<Callout tone="amber" title="Reflection status">
  Reflection is implemented but still experimental. FieldInfo and PropertyInfo expose name, type,
  {' '}and static-ness, but they do not yet surface the underlying slot index or byte offset to
  {' '}ShardScript code. Accessing fields by reflection is not supported; use normal field access
  {' '}for production code.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Inspecting a type through reflection.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using collections;
using reflection;

namespace demo;

public class Counter
{
    public Name: string;
    public Count: int;

    public init(name: string)
    {
        this.Name = name;
        this.Count = 0;
    }
}

public static func Main() -> void
{
    c: Counter = new Counter("ticks");
    t: Type = Type.Of(c);

    println("type: " + t.FullName);
    println("is class: " + t.IsClass);
    println("is generic: " + t.IsGeneric);

    fields: FieldInfo[] = t.GetFields();
    println("fields: " + fields.Length);

    foreach (f: FieldInfo in fields)
    {
        println("  " + f.Name + " : " + f.FieldType.Name + " (static=" + f.IsStatic + ")");
    }
}`}
  language="csharp"
  filename="reflection_typeshape.shard"
/>

<Prose>
  <strong>Generic instantiations have distinct shapes.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using collections;
using reflection;

namespace demo;

public static func Main() -> void
{
    ints: List<int> = new List<int>();
    strings: List<string> = new List<string>();

    typeInts: Type = Type.Of(ints);
    typeStrings: Type = Type.Of(strings);

    println(typeInts.FullName);              // the closed generic name
    println(typeStrings.FullName);
    println(typeInts.IsGeneric);             // true
    println(typeStrings.IsGeneric);          // true

    // The two closed instantiations are different runtime types.
    println(typeInts == typeStrings);        // false

    // Enumerating the fields shows the concrete substituted field types.
    println("List<int> fields:");
    foreach (f: FieldInfo in typeInts.GetFields())
    {
        println("  " + f.Name + " : " + f.FieldType.Name);
    }
}`}
  language="csharp"
  filename="generic_shapes.shard"
/>

<Prose>
  <strong>Value types are embedded inline.</strong> The <InlineCode>Point</InlineCode> struct below
  {' '}has two <InlineCode>int</InlineCode> fields. Its shape is 16 bytes with slot 0 at offset 0 and
  {' '}slot 1 at offset 8.
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public struct Point
{
    public X: int;
    public Y: int;
}

public static func Main() -> void
{
    p: Point = new Point();
    p.X = 3;
    p.Y = 4;

    println(p.X);   // 3
    println(p.Y);   // 4
}`}
  language="csharp"
  filename="struct_inline.shard"
/>

<Callout tone="blue">
  Because <InlineCode>Point</InlineCode> is a struct, a <InlineCode>Point</InlineCode> field inside
  {' '}another type is stored inline at its full 16-byte size. A class field, by contrast, stores
  {' '}only a pointer.
</Callout>

<Prose>
  <strong>Common mistake: recursive struct inlining.</strong> A struct cannot contain an instance of
  {' '}itself by value. Use a reference type or a pointer-sized handle to break the cycle.
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

// ERROR: Recursive struct inlining.
// public struct Node
// {
//     public Value: int;
//     public Next: Node;     // infinite size
// }

// Correct: reference types store a pointer, breaking the cycle.
public class Node
{
    public Value: int;
    public Next: Node;
}

public static func Main() -> void
{
    first: Node = new Node();
    first.Value = 1;
    first.Next = new Node();
    first.Next.Value = 2;

    println(first.Value);       // 1
    println(first.Next.Value);  // 2
}`}
  language="csharp"
  filename="recursive_struct.shard"
/>

<Prose>
  <strong>Common mistake: confusing static and instance fields.</strong> Static fields are not part
  {' '}of the instance shape and do not appear in <InlineCode>GetFields()</InlineCode> as instance
  {' '}slots.
</Prose>

<CodeBlock
  code={`using stdio;
using reflection;

namespace demo;

public class Settings
{
    public static Version: int = 1;
    public Name: string;
}

public static func Main() -> void
{
    s: Settings = new Settings();
    s.Name = "demo";

    println(Settings.Version);   // 1
    println(s.Name);             // demo

    // GetFields returns only instance fields; Version is static.
    fields: FieldInfo[] = Type.Of(s).GetFields();
    println("instance fields: " + fields.Length);   // 1
}`}
  language="csharp"
  filename="static_vs_instance.shard"
/>
