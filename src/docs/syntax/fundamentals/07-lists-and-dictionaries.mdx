<Prose>
  The <InlineCode>shard.collections</InlineCode> shard provides two generic container types:
  <InlineCode>List&lt;T&gt;</InlineCode> (a growable, ordered sequence) and{' '}
  <InlineCode>Dictionary&lt;K, V&gt;</InlineCode> (a hash map from keys to values). Both live in the{' '}
  <InlineCode>collections</InlineCode> namespace, require <InlineCode>using collections;</InlineCode>,
  and support indexers, explicit mutation, and <InlineCode>foreach</InlineCode> enumeration.
</Prose>

<H2>Summary</H2>

<Prose>
  <InlineCode>List&lt;T&gt;</InlineCode> stores elements in insertion order and exposes a zero-based
  integer indexer, an <InlineCode>Add</InlineCode> method, a <InlineCode>RemoveAt</InlineCode> method,
  and a <InlineCode>Length</InlineCode> property. <InlineCode>Dictionary&lt;K, V&gt;</InlineCode> maps
  keys to values using a hash table and exposes a key-based indexer, <InlineCode>Add</InlineCode>,{' '}
  <InlineCode>ContainsKey</InlineCode>, <InlineCode>Remove</InlineCode>, and a <InlineCode>Count</InlineCode>{' '}
  property. Both types implement the enumerable contract used by <InlineCode>foreach</InlineCode>.
</Prose>

<H2>Syntax</H2>

<CodeBlock
  code={`using collections;

// Construction
list: List<int> = new List<int>();
listWithRoom: List<int> = new List<int>(16);

// Enumeration

    // item has type T
}

<H2>Exceptions / Errors</H2>

<ul className="space-y-3">
  <Bullet>
    <strong className="text-text-primary">List index out of bounds</strong> —{' '}
    <InlineCode>list[index]</InlineCode> (get or set), <InlineCode>ElementAt(index)</InlineCode>, and{' '}
    <InlineCode>RemoveAt(index)</InlineCode> throw when <InlineCode>index</InlineCode> is negative or
    greater than or equal to <InlineCode>list.Length</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Dictionary key already exists</strong> —{' '}
    <InlineCode>dict.Add(key, value)</InlineCode> throws if <InlineCode>key</InlineCode> is already in
    the dictionary. Use the indexer set syntax to insert-or-update instead.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Dictionary key not found</strong> —{' '}
    <InlineCode>dict[key]</InlineCode> (get) throws when the key is absent. Prefer{' '}
    <InlineCode>ContainsKey</InlineCode> or <InlineCode>Remove</InlineCode> to guard against missing
    keys.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Missing namespace import</strong> — Forgetting{' '}
    <InlineCode>using collections;</InlineCode> produces a compile-time error because the compiler
    cannot resolve <InlineCode>List</InlineCode> or <InlineCode>Dictionary</InlineCode>.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <InlineCode>List&lt;T&gt;</InlineCode> stores its elements in a private backing array. In the
  current implementation, every call to <InlineCode>Add</InlineCode> allocates a brand-new array one
  element larger and copies every existing element into it. Appends are therefore{' '}
  <InlineCode>O(n)</InlineCode> rather than amortized <InlineCode>O(1)</InlineCode>, so very large
  lists should be built with care. <InlineCode>RemoveAt</InlineCode> is also{' '}
  <InlineCode>O(n)</InlineCode> because it shifts all later elements down. The capacity constructor
  only avoids the first few reallocations; it does not change the copy-on-add behavior.
</Prose>

<Prose>
  <InlineCode>Dictionary&lt;K, V&gt;</InlineCode> is implemented as an open-addressing hash table with
  linear probing. The internal table doubles in size once the load factor exceeds 0.75, and removed
  slots are marked as tombstones so that probe chains remain intact. Enumeration yields entries in
  internal slot order, which is not guaranteed to match insertion order. The <InlineCode>Keys</InlineCode>{' '}
  and <InlineCode>Values</InlineCode> properties allocate a new array on every access, so cache the
  result if it is needed repeatedly.
</Prose>

<Prose>
  Both types implement the enumerable contract used by <InlineCode>foreach</InlineCode>. A{' '}
  <InlineCode>List&lt;T&gt;</InlineCode> enumeration yields elements of type <InlineCode>T</InlineCode>.
  A <InlineCode>Dictionary&lt;K, V&gt;</InlineCode> enumeration yields{' '}
  <InlineCode>KeyValuePair&lt;K, V&gt;</InlineCode> instances whose public fields are{' '}
  <InlineCode>Key</InlineCode> and <InlineCode>Value</InlineCode>.
</Prose>

<Callout tone="blue">
  Key hashing and equality are supported for primitives (<InlineCode>int</InlineCode>,{' '}
  <InlineCode>char</InlineCode>, <InlineCode>bool</InlineCode>, <InlineCode>double</InlineCode>, and{' '}
  <InlineCode>string</InlineCode>) by value. For other reference types, the dictionary falls back to
  identity-based hashing and equality, which means two different object instances are never equal
  even if their fields match.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Basic List usage</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using collections;

namespace demo;

public static func Main() -> void
{
    list: List<string> = new List<string>();

    // Add appends items in order.
    list.Add("alpha");
    list.Add("beta");
    list.Add("gamma");

    println(list.Length);   // 3
    println(list[0]);       // alpha
    println(list[2]);       // gamma

    // Replace an element through the indexer.
    list[1] = "BETA";
    println(list[1]);       // BETA

    // Remove the first element; later elements shift down.
    list.RemoveAt(0);
    println(list.Length);   // 2
    println(list[0]);       // BETA

    // foreach visits elements from index 0 upward.
    foreach (word in list)
    {
        println(word);      // BETA, then gamma
    }
}`}
  language="csharp"
  filename="list_basic.shard"
/>

<Prose>
  <strong>Basic Dictionary usage</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using collections;

namespace demo;

public static func Main() -> void
{
    ages: Dictionary<string, int> = new Dictionary<string, int>();

    ages.Add("alice", 30);
    ages.Add("bob", 25);
    ages.Add("carol", 27);

    println(ages.Count);            // 3
    println(ages["alice"]);         // 30

    // Indexer set updates an existing value.
    ages["bob"] = 26;
    println(ages["bob"]);           // 26

    // ContainsKey tests presence without throwing.
    println(ages.ContainsKey("bob"));   // true
    println(ages.ContainsKey("dave"));  // false

    // Remove reports whether the key existed.
    removed: bool = ages.Remove("carol");
    println(removed);               // true
    println(ages.Count);            // 2

    // foreach yields KeyValuePair<string, int> in internal slot order.
    foreach (pair in ages)
    {
        println(pair.Key + " = " + pair.Value);
    }
}`}
  language="csharp"
  filename="dictionary_basic.shard"

<Prose>
  <strong>Edge cases and exception handling</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using collections;

namespace demo;

public static func Main() -> void
{
    list: List<int> = new List<int>();
    list.Add(10);

    // Negative indices are always rejected.
    try
    {
        value: int = list[-1];
        println(value);
    }
    catch (ex: RuntimeException)
    {
        println("caught: negative list index");
    }

    dict: Dictionary<int, string> = new Dictionary<int, string>();
    dict.Add(1, "one");

    // Duplicate keys are rejected by Add.
    try
    {
        dict.Add(1, "ONE");
    }
    catch (ex: RuntimeException)
    {
        println("caught: duplicate key");
    }

    // Missing keys are rejected by the indexer getter.
    try
    {
        missing: string = dict[42];
        println(missing);
    }
    catch (ex: RuntimeException)
    {
        println("caught: missing key");
    }

    // Remove returns false without throwing when the key is absent.
    removed: bool = dict.Remove(99);
    println(removed);   // false
}`}

<Prose>
  <strong>Common mistakes</strong>
</Prose>

<ul className="space-y-3">
  <Bullet>
    <strong className="text-text-primary">Using Count on a List</strong> —{' '}
    <InlineCode>List&lt;T&gt;</InlineCode> exposes <InlineCode>Length</InlineCode>, not{' '}
    <InlineCode>Count</InlineCode>. The opposite is true for dictionaries: they expose{' '}
    <InlineCode>Count</InlineCode>, not <InlineCode>Length</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Mutating while enumerating</strong> — Adding or removing
    elements from a list after creating an enumerator does not update that enumerator; the loop may
    see stale data or skip elements. Clear the collection only after the loop completes.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Treating Dictionary order as meaningful</strong> — The
    order produced by <InlineCode>foreach</InlineCode> reflects the internal hash-table layout, not
    the order in which keys were inserted.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Forgetting the using directive</strong> — Both types live
    in the <InlineCode>collections</InlineCode> namespace. Without{' '}
    <InlineCode>using collections;</InlineCode> the compiler reports an unresolved type error.
  </Bullet>
</ul>
