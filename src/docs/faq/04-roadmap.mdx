<H2>Summary</H2>

<Prose>
  ShardScript is a working language and runtime. The compiler, virtual machine, event loop, standard
  library shards, and native-library framework are all functional today. Ongoing work focuses on expanding
  the standard library, improving tooling, and maturing the package ecosystem.
</Prose>

<H2>What problem it solves</H2>

<Prose>
  A young language needs clear expectations. This roadmap describes what is already available, what is
  actively being developed, and what remains future work, so users can decide whether ShardScript is ready
  for their project.
</Prose>

<H2>How the roadmap is organized</H2>

<Prose>
  Items are grouped by maturity: <strong>Available now</strong> ships in the repository today,
  <strong>Near term</strong> is under active development or design, and <strong>Future</strong> is planned
  but not yet scheduled. The roadmap is a snapshot; the source repository remains the authoritative status.
</Prose>

<H2>Key ideas</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Core runtime is stable.</strong> Lexing, parsing, semantic
    analysis, async lowering, bytecode emission, VM execution, garbage collection, and the libuv event loop
    are all implemented.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Standard library is growing.</strong> Core I/O, collections,
    math, text, JSON, files, processes, networking, async primitives, reflection, time, and interop shards
    exist, with more coverage planned.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Tooling is expanding.</strong> A language server is part of the
    ecosystem; future work includes richer diagnostics and editor integration.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Package management is on the horizon.</strong> Geode is the
    planned package manager, but it is not yet shipped.
  </Bullet>
</ul>

<H2>When to use / When not to use</H2>

<Prose>
  ShardScript is usable today for embedded scripting, native-library extensions, and I/O-heavy applications
  that fit its cooperative concurrency model. It is not yet a mature ecosystem with a broad third-party
  package market or IDE marketplace, so evaluate it against the features that are actually shipped.
</Prose>
