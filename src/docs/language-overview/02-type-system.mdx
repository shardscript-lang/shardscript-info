<H2>Summary</H2>

<Prose>
  The ShardScript type system is strictly static: every variable, parameter, field, property, and return
  type has a compile-time type. The system distinguishes value types from reference types, supports generic
  type parameters, arrays, interface contracts, and enums, and uses explicit casts rather than implicit
  numeric widening.
</Prose>

<H2>What problem it solves</H2>

<Prose>
  Embedded scripting languages often trade compile-time safety for ease of use. ShardScript keeps the
  embedding model lightweight while catching type mismatches, missing members, and contract violations before
  the script runs. A clear type system also makes code easier to read, refactor, and call from native code.
</Prose>

<H2>How it works</H2>

<Prose>
  Types are resolved during semantic analysis. The compiler checks assignments, argument passing, return
  values, interface implementations, and generic instantiations. Once analysis succeeds, the bytecode
  emitter uses the resolved types to choose opcodes and layouts. At runtime the virtual machine stores
  value types inline and reference types as garbage-collected heap references.
</Prose>

<H2>Key ideas</H2>

<Prose>
  <strong>Value types.</strong> <InlineCode>int</InlineCode>, <InlineCode>double</InlineCode>,{" "}
  <InlineCode>bool</InlineCode>, <InlineCode>char</InlineCode>, <InlineCode>byte</InlineCode>,{" "}
  <InlineCode>nint</InlineCode>, and user-defined <InlineCode>struct</InlineCode> types are value types.
  Assignment copies the value. Value types live inline in locals, object fields, and array slots.
</Prose>

<Prose>
  <strong>Reference types.</strong> <InlineCode>string</InlineCode>, classes, arrays, delegates, and
  interface references are reference types. Assignment copies the reference, not the object. Multiple
  references can point to the same heap object, so mutations are visible through every reference.
</Prose>

<Prose>
  <strong>Generics.</strong> Classes, structs, methods, delegates, and extension methods can declare type
  parameters such as <InlineCode>T</InlineCode>. The compiler substitutes concrete type arguments at
  compile time, and the runtime builds a distinct layout for every instantiation. Type inference can
  deduce method type arguments from the call site.
</Prose>

<Prose>
  <strong>Arrays.</strong> An array <InlineCode>T[]</InlineCode> is a fixed-size, homogeneous, indexed
  sequence. Arrays are reference types allocated on the GC heap. Bounds are checked at runtime.
</Prose>

<Prose>
  <strong>Interfaces.</strong> An interface declares a contract of methods and properties. A class or struct
  implements the contract by providing matching public members. Calls through an interface are dispatched at
  runtime.
</Prose>

<Prose>
  <strong>Enums.</strong> Enums are value types that name a set of integral constants. They support equality,
  bitwise operations for flags enums, and automatic string formatting through <InlineCode>ToString()</InlineCode>.
</Prose>

<Prose>
  <strong>Nullable references.</strong> Reference-type variables may hold <InlineCode>null</InlineCode>. The
  compiler does not track nullability; a <InlineCode>null</InlineCode> check, a cast followed by a guard, or
  a defensive <InlineCode>is</InlineCode> test is required before dereferencing a reference of unknown origin.
</Prose>

<Prose>
  <strong>Explicit conversions.</strong> ShardScript does not implicitly widen numeric types on assignment
  or argument passing. Use the <InlineCode>as</InlineCode> operator to convert between scalar primitives or
  along an inheritance chain.
</Prose>

<H2>When to use / When not to use</H2>

<DocsTable
  headers={['Use', 'Avoid']}
  rows={[
    [
      <>Use value types for small, immutable, frequently-copied data such as coordinates, identifiers, and flags.</>,
      <>Do not use value types for large objects that are shared and mutated through multiple references; prefer classes.</>,
    ],
    [
      <>Use classes for object identity, shared mutable state, and interface implementation.</>,
      <>Do not use classes for pure value semantics where accidental aliasing would cause bugs; prefer structs.</>,
    ],
    [
      <>Use generics when the same algorithm or container works for several concrete types.</>,
      <>Do not use generics when every type argument needs a different implementation; prefer explicit types or interfaces.</>,
    ],
    [
      <>Use interfaces to decouple callers from concrete implementations.</>,
      <>Do not use interfaces for single-concrete-type scenarios where direct calls are clearer and cheaper.</>,
    ],
    [
      <>Use enums for a closed set of named constants.</>,
      <>Do not use enums for open sets or values that need runtime extensibility; prefer constants or classes.</>,
    ],
  ]}
/>

<H2>Examples</H2>

<Prose>
  <strong>Value versus reference semantics.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public struct Point
{
    public X: int;
    public Y: int;
}

public class Counter
{
    public Value: int;
}

public static func Main() -> void
{
    // Value type: assignment copies the whole value.
    a: Point = new Point();
    a.X = 1;
    b: Point = a;
    b.X = 2;
    println(a.X);   // 1
    println(b.X);   // 2

    // Reference type: assignment copies the reference.
    c: Counter = new Counter();
    c.Value = 1;
    d: Counter = c;
    d.Value = 2;
    println(c.Value); // 2
    println(d.Value); // 2
}`}
  language="csharp"
  filename="value_vs_reference.shard"
/>

<Prose>
  <strong>Generic container and type inference.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public class Pair<T>
{
    public First: T;
    public Second: T;
}

public static func MakePair<T>(first: T, second: T) -> Pair<T>
{
    pair: Pair<T> = new Pair<T>();
    pair.First = first;
    pair.Second = second;
    return pair;
}

public static func Main() -> void
{
    // Explicit type argument.
    numbers: Pair<int> = MakePair<int>(10, 20);
    println(numbers.First);   // 10

    // Inferred type argument: T is string from the arguments.
    words: Pair<string> = MakePair("hello", "world");
    println(words.Second);    // world
}`}
  language="csharp"
  filename="generics_example.shard"
/>

<Prose>
  <strong>Arrays, ranges, and iteration.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public static func Main() -> void
{
    // Literal array.
    values: int[] = [10, 20, 30];
    println(values.Length);   // 3

    // Range produces an int[].
    range: int[] = 1..4;
    foreach (n in range)
    {
        println(n);           // 1, 2, 3
    }

    // Reference-type array.
    items: string[] = new string[2];
    items[0] = "first";
    items[1] = "second";
    println(items[0]);        // first
}`}
  language="csharp"
  filename="arrays_example.shard"
/>

<Prose>
  <strong>Interfaces and polymorphism.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public interface ILogger
{
    func Log(message: string) -> void;
}

public class ConsoleLogger : ILogger
{
    public func Log(message: string) -> void
    {
        println(message);
    }
}

public static func WriteLog(logger: ILogger, message: string) -> void
{
    logger.Log(message);
}

public static func Main() -> void
{
    logger: ILogger = new ConsoleLogger();
    WriteLog(logger, "typed contract");   // typed contract
}`}

<Prose>
  <strong>Enums and flags.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public enum Status
{
    Pending,
    Running,
    Completed
}

public enum Permissions : flags
{
    None,
    Read,
    Write,
    Execute
}

public static func Main() -> void
{
    status: Status = Status.Running;
    println(status);                         // Running

    access: Permissions = Permissions.Read | Permissions.Write;
    println(access);                         // Read | Write
    println(access.HasFlag(Permissions.Read)); // true
}`}

<Prose>
  <strong>Explicit casts and null handling.</strong>
</Prose>

<CodeBlock
  code={`using stdio;

namespace demo;

public class Shape
{
    public Name: string;

    public init(name: string)
    {
        this.Name = name;
    }
}

public static func Main() -> void
{
    // Explicit numeric cast.
    ratio: double = 7 as double;
    println(ratio);   // 7.0

    // Safe reference cast with a null guard.
    shape: Shape = new Shape("circle");
    maybe: Shape = shape as Shape;

    if (maybe != null)
    {
        println(maybe.Name);   // circle
    }
}`}
  language="csharp"
  filename="casts_and_nulls.shard"
