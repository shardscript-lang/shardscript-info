<Prose>
  Every native callback receives its inputs through <InlineCode>context.Args</InlineCode>, a{' '}
  <InlineCode>std::span&lt;ObjectInstance*&gt;</InlineCode>. For static members the first element is the first
  real argument; for instance members the first element is <InlineCode>this</InlineCode>. This guide shows how
  to extract primitive values, guard reference arguments against <InlineCode>nullptr</InlineCode>, and use the
  convenience helper for simple parameter lists.
</Prose>

<H2>Prerequisites</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    A working C++20 toolchain and a way to build a shared library (CMake, MSBuild, or another build system).
  </Bullet>
  <Bullet>
    The ShardScript runtime headers, normally located in <InlineCode>ShardScript/include</InlineCode>, and the
    ShardScript runtime shared library to link against.
  </Bullet>
  <Bullet>
    Familiarity with <InlineCode>SHARDLIB_GETMETADATA</InlineCode>,{' '}
    <InlineCode>SHARDLIB_ENTRYPOINT</InlineCode>, and the <InlineCode>SymbolBuilder</InlineCode> registration API.
  </Bullet>
</ul>

<H2>Goal</H2>

<Prose>
  Read incoming <InlineCode>ObjectInstance*</InlineCode> arguments inside a native callback as strongly typed C++
  values. Cover every primitive reader — <InlineCode>AsInteger</InlineCode>, <InlineCode>AsDouble</InlineCode>,{' '}
  <InlineCode>AsBoolean</InlineCode>, <InlineCode>AsCharacter</InlineCode>, <InlineCode>AsByte</InlineCode>,{' '}
  <InlineCode>AsString</InlineCode>, and <InlineCode>AsNint</InlineCode> — plus null checks and the{' '}
  <InlineCode>GetArgs&lt;T...&gt;</InlineCode> helper.
</Prose>

<H2>Step-by-Step Instructions</H2>

<Prose>
  <strong>1. Remember the argument layout.</strong>
</Prose>

<Prose>
  A native callback has the same signature regardless of whether the method is static or instance:
</Prose>

<CodeBlock
  code={`shard::ObjectInstance* Callback(const shard::CallState& context);`}
  language="cpp"
/>

<Prose>
  The <InlineCode>context.Args</InlineCode> span contains the arguments exactly as they were passed from
  ShardScript. For static methods, <InlineCode>Args[0]</InlineCode> is the first real argument. For instance
  methods, <InlineCode>Args[0]</InlineCode> is <InlineCode>this</InlineCode> and the real parameters start at{' '}
  <InlineCode>Args[1]</InlineCode>.
</Prose>

<Callout tone="blue">
  Register a method with <InlineCode>LINK_STATIC</InlineCode> when it has no implicit{' '}
  <InlineCode>this</InlineCode>, and with <InlineCode>LINK_INSTANCE</InlineCode> when it is called on an object.
  A mismatch will shift every argument index and usually corrupt the value types you read.
</Callout>

<Prose>
  <strong>2. Read primitive arguments.</strong>
</Prose>

<Prose>
  <InlineCode>ObjectInstance</InlineCode> provides typed readers for every ShardScript primitive. Use the
  appropriate reader for the declared parameter type.
</Prose>

<CodeBlock
  code={`std::int64_t integerValue   = context.Args[0]->AsInteger();
double       doubleValue    = context.Args[0]->AsDouble();
bool         booleanValue   = context.Args[0]->AsBoolean();
wchar_t      characterValue = context.Args[0]->AsCharacter();
std::uint8_t byteValue      = context.Args[0]->AsByte();
const wchar_t* stringValue  = context.Args[0]->AsString();
void*        nativePointer  = context.Args[0]->AsNint();`}
  language="cpp"
/>

<DocsTable
  headers={['Reader', 'C++ return type', 'ShardScript type']}
  rows={[
    [<InlineCode>AsInteger()</InlineCode>, <InlineCode>std::int64_t</InlineCode>, <InlineCode>int</InlineCode>],
    [<InlineCode>AsDouble()</InlineCode>, <InlineCode>double</InlineCode>, <InlineCode>double</InlineCode>],
    [<InlineCode>AsBoolean()</InlineCode>, <InlineCode>bool</InlineCode>, <InlineCode>bool</InlineCode>],
    [<InlineCode>AsCharacter()</InlineCode>, <InlineCode>wchar_t</InlineCode>, <InlineCode>char</InlineCode>],
    [<InlineCode>AsByte()</InlineCode>, <InlineCode>std::uint8_t</InlineCode>, <InlineCode>byte</InlineCode>],
    [<InlineCode>AsString()</InlineCode>, <InlineCode>const wchar_t*</InlineCode>, <InlineCode>string</InlineCode>],
    [<InlineCode>AsNint()</InlineCode>, <InlineCode>void*</InlineCode>, <InlineCode>nint</InlineCode>],
  ]}
/>

<Prose>
  <strong>3. Guard reference arguments against null.</strong>
</Prose>

<Prose>
  String, object, and array arguments can be <InlineCode>nullptr</InlineCode> or the singleton{' '}
  <InlineCode>GarbageCollector::NullInstance</InlineCode>. Always test before dereferencing them. For strings,
  return an empty managed string or throw a runtime error instead of crashing inside{' '}
  <InlineCode>AsString()</InlineCode>.
</Prose>

<CodeBlock
  code={`ObjectInstance* arg = context.Args[0];

if (arg == nullptr || arg == GarbageCollector::NullInstance)
{
    // Return a safe default instead of dereferencing a null reference argument.
    return context.Collector.FromValue(std::wstring());
}

const wchar_t* text = arg->AsString();`}
  language="cpp"
/>

<Prose>
  <strong>4. Read strings safely.</strong>
</Prose>

<Prose>
  <InlineCode>AsString()</InlineCode> returns a pointer into a GC-managed instance. Copy the contents into a{' '}
  <InlineCode>std::wstring</InlineCode> if you need to keep the text after the callback returns or pass it to
  code that may trigger garbage collection.
</Prose>

<CodeBlock
  code={`ObjectInstance* arg = context.Args[0];

if (arg == nullptr || arg == GarbageCollector::NullInstance)
{
    return context.Collector.FromValue(std::wstring());
}

std::wstring text = arg->AsString();

// Transform the local copy; the original GC-owned buffer stays borrowed.
std::transform(text.begin(), text.end(), text.begin(), ::towupper);

return context.Collector.FromValue(text);`}
  language="cpp"
/>

<Prose>
  <strong>5. Read native pointer arguments.</strong>
</Prose>

<Prose>
  Use <InlineCode>AsNint()</InlineCode> for opaque native pointers stored in a <InlineCode>nint</InlineCode>{' '}
  field or parameter. Because the value is a raw pointer, it is especially important to validate it before
  use.
</Prose>

<CodeBlock
  code={`ObjectInstance* arg = context.Args[0];

if (arg == nullptr || arg == GarbageCollector::NullInstance)
{
    return context.Collector.FromValue(static_cast<std::int64_t>(0));
}

void* nativePointer = arg->AsNint();

if (nativePointer == nullptr)
{
    return context.Collector.FromValue(static_cast<std::int64_t>(0));
}

std::int64_t address = reinterpret_cast<std::int64_t>(nativePointer);
return context.Collector.FromValue(address);`}
  language="cpp"
/>

<Prose>
  <strong>6. Use the <InlineCode>GetArgs&lt;T...&gt;</InlineCode> helper for multiple primitives.</strong>
</Prose>

<Prose>
  For simple static methods whose arguments are all primitives, the <InlineCode>GetArgs&lt;T...&gt;</InlineCode>
  helper unpacks <InlineCode>context.Args</InlineCode> in order. It is used extensively in libraries such as{' '}
  <InlineCode>system/math.shard.cpp</InlineCode>.
</Prose>

<CodeBlock
  code={`// Read one primitive argument.
auto [value] = GetArgs<double>(context);

// Read two primitive arguments.
auto [a, b] = GetArgs<double, double>(context);

// Read mixed primitive arguments.
auto [base, exponent] = GetArgs<double, int>(context);

// Read self instance with mixed primitive arguments.
auto [self, base, exponent] = GetArgs<ObjectInstance*, double, int>(context);

double result = std::pow(base, static_cast<double>(exponent));
return context.Collector.FromValue(result);`}
  language="cpp"
/>

<Callout tone="blue">
  Structured bindings require the <InlineCode>auto</InlineCode> placeholder in C++. The actual types come from
  the explicit template arguments to <InlineCode>GetArgs</InlineCode>, so the types are still fixed at compile
  time.
</Callout>

<Prose>
  <strong>7. Put the pieces together in a single library.</strong>
</Prose>

<Prose>
  The following library registers a static class with several methods. Each method demonstrates one reading
  pattern: primitives, null-safe strings, native pointers, and the <InlineCode>GetArgs</InlineCode> helper.
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>

#include <algorithm>
#include <cmath>
#include <cstdint>
#include <string>

using namespace shard;

static ObjectInstance* ReadPrimitives(const CallState& context)
{
    // Args[0] is the first real argument because the method is LINK_STATIC.
    std::int64_t integerValue   = context.Args[0]->AsInteger();
    double       doubleValue    = context.Args[1]->AsDouble();
    bool         booleanValue   = context.Args[2]->AsBoolean();
    wchar_t      characterValue = context.Args[3]->AsCharacter();
    std::uint8_t byteValue      = context.Args[4]->AsByte();

    double result = static_cast<double>(integerValue) + doubleValue;

    if (booleanValue)
    {
        result = result + static_cast<double>(characterValue) + static_cast<double>(byteValue);
    }

    return context.Collector.FromValue(result);
}

static ObjectInstance* SafeStringLength(const CallState& context)
{
    ObjectInstance* arg = context.Args[0];

    if (arg == nullptr || arg == GarbageCollector::NullInstance)
    {
        // Return 0 for a null string instead of dereferencing it.
        return context.Collector.FromValue(static_cast<std::int64_t>(0));
    }

    std::wstring text = arg->AsString();
    std::int64_t length = static_cast<std::int64_t>(text.length());

    return context.Collector.FromValue(length);
}

static ObjectInstance* PointerAddress(const CallState& context)
{
    ObjectInstance* arg = context.Args[0];

    if (arg == nullptr || arg == GarbageCollector::NullInstance)
    {
        return context.Collector.FromValue(static_cast<std::int64_t>(0));
    }

    void* pointer = arg->AsNint();

    if (pointer == nullptr)
    {
        return context.Collector.FromValue(static_cast<std::int64_t>(0));
    }

    std::int64_t address = reinterpret_cast<std::int64_t>(pointer);
    return context.Collector.FromValue(address);
}

static ObjectInstance* Power(const CallState& context)
{
    auto [base, exponent] = GetArgs<double, int>(context);

    double result = std::pow(base, static_cast<double>(exponent));
    return context.Collector.FromValue(result);
}

SHARDLIB_GETMETADATA
{
    lib.Name        = L"shard.argdemo";
    lib.Description = L"Argument reading demonstrations";
    lib.Version     = L"1.0.0";
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> argDemo(context, L"argdemo");

    argDemo.AddClass(L"ArgDemo", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> type)
    {
        type.AddMethod(L"ReadPrimitives", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"i", TYPE_INT)
            .AddParameter(L"d", TYPE_DOUBLE)
            .AddParameter(L"b", TYPE_BOOL)
            .AddParameter(L"c", TYPE_CHAR)
            .AddParameter(L"y", TYPE_BYTE)
            .SetCallback(&ReadPrimitives);

        type.AddMethod(L"SafeStringLength", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"s", TYPE_STRING)
            .SetCallback(&SafeStringLength);

        type.AddMethod(L"PointerAddress", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"p", TYPE_NINT)
            .SetCallback(&PointerAddress);

        type.AddMethod(L"Power", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"base", TYPE_DOUBLE)
            .AddParameter(L"exponent", TYPE_INT)
            .SetCallback(&Power);
    });
}`}
  language="cpp"
  filename="argdemo.cpp"
/>

<H2>Verification</H2>

<Prose>
  Build the shared library from the source file above and load it with the <InlineCode>-l</InlineCode> flag.
  The runtime loads any shared library that exports <InlineCode>ShardLib_GetMetadata</InlineCode> and{' '}
  <InlineCode>ShardLib_EntryPoint</InlineCode>, whether the library lives inside{' '}
  <InlineCode>ShardScript.Framework</InlineCode> or in its own directory.
</Prose>

<CodeBlock
  code={`using stdio;
using argdemo;

namespace demo;

public static func Main() -> void
{
    double combined = ArgDemo.ReadPrimitives(10, 2.5, true, 'A', 5);
    println("combined: " + combined);

    int stringLength = ArgDemo.SafeStringLength("ShardScript");
    println("length: " + stringLength);

    int nullLength = ArgDemo.SafeStringLength(null);
    println("null length: " + nullLength);

    nint ptr = cinterop.Alloc(64);
    int address = ArgDemo.PointerAddress(ptr);
    println("address non-zero: " + (address != 0));

    double powerResult = ArgDemo.Power(2.0, 8);
    println("power: " + powerResult);
}`}
  language="csharp"
  filename="app.shard"
/>

<Callout tone="blue">
  The <InlineCode>cinterop.Alloc</InlineCode> call above assumes the <InlineCode>shard.cinterop</InlineCode>{' '}
  library is loaded. If it is not available in your environment, replace the pointer assignment with{' '}
  <InlineCode>nint ptr = 0</InlineCode> and verify that <InlineCode>PointerAddress</InlineCode> returns 0.
</Callout>

<H2>Troubleshooting</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary"><InlineCode>AsString()</InlineCode> crashes.</strong> The argument
    was probably <InlineCode>null</InlineCode>. Always check for <InlineCode>nullptr</InlineCode> and{' '}
    <InlineCode>GarbageCollector::NullInstance</InlineCode> before calling <InlineCode>AsString()</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Primitive values look corrupted.</strong> Verify the method's{' '}
    <InlineCode>SymbolLinking</InlineCode>. For instance methods, <InlineCode>Args[0]</InlineCode> is{' '}
    <InlineCode>this</InlineCode>; for static methods, <InlineCode>Args[0]</InlineCode> is the first real
    argument. A mismatch shifts every index.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary"><InlineCode>GetArgs</InlineCode> throws or returns garbage.</strong>
    Ensure the number and order of template arguments exactly match the registered parameter list. Mismatched
    types cause the readers to interpret the wrong object layout.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">String data disappears after a GC call.</strong>{' '}
    <InlineCode>AsString()</InlineCode> returns a borrowed pointer into a managed object. Copy it into a{' '}
    <InlineCode>std::wstring</InlineCode> if you keep it past the next allocation or collection point.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary"><InlineCode>AsNint()</InlineCode> returns an unexpected address.</strong>
    Confirm the ShardScript side passed the pointer through a <InlineCode>nint</InlineCode> parameter, not an
    object reference. Native pointers are not subject to GC tracking, so type mismatches are not caught at
    runtime.
  </Bullet>
</ul>
