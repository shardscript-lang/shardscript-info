<H2>Summary</H2>

<Prose>
  The <InlineCode>{'SymbolBuilder<EnumSymbol>'}</InlineCode> API registers enum types into the ShardScript
  semantic model from a native C++ library. It supports both plain enums and flag enums through
  <InlineCode>AddEnum</InlineCode>, <InlineCode>AddValue</InlineCode>, and <InlineCode>SetFlags</InlineCode>.
</Prose>

<H2>Syntax</H2>

<Prose>
  Enums are created from a <InlineCode>{'SymbolBuilder<NamespaceSymbol>'}</InlineCode>. The returned enum
  builder exposes two chainable registration methods.
</Prose>

<CodeBlock
  code={`SymbolBuilder<EnumSymbol> SymbolBuilder<NamespaceSymbol>::AddEnum(
    const std::wstring& name,
    bool isFlags = false,
    SymbolAccesibility access = SymbolAccesibility::Public);

SymbolBuilder<EnumSymbol>& SymbolBuilder<EnumSymbol>::SetFlags(bool value = true);

SymbolBuilder<EnumSymbol>& SymbolBuilder<EnumSymbol>::AddValue(
    const std::wstring& name,
    std::int64_t value);`}
  language="cpp"
/>

<H2>Returns</H2>

<Prose>
  <InlineCode>AddEnum</InlineCode> returns a <InlineCode>{'SymbolBuilder<EnumSymbol>'}</InlineCode> by value
  that owns the newly created <InlineCode>EnumSymbol</InlineCode>. <InlineCode>SetFlags</InlineCode> and
  <InlineCode>AddValue</InlineCode> return a reference to the same builder so calls can be chained. The
  builder also converts implicitly to <InlineCode>EnumSymbol*</InlineCode>, which is useful when passing the
  enum as a parameter type to methods.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Duplicate member name</strong> — Calling{' '}
    <InlineCode>AddValue</InlineCode> with a name that already exists on the enum produces a semantic
    duplicate-declaration error.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Conflicting flag values</strong> — For flags enums, values that
    overlap unintentionally cause surprising <InlineCode>HasFlag</InlineCode> results. Each flag should be a
    distinct power of two, and the zero value should represent the empty combination.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Name collision in the namespace</strong> — The enum name must not
    conflict with another type or namespace member already declared in the same scope.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Accessibility mismatch</strong> — An enum registered with{' '}
    <InlineCode>ACS_PRIVATE</InlineCode> cannot be referenced from
    ShardScript code outside its visibility boundary, even though the native registration succeeds.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Callout tone="blue" title="Native library shape">
  A ShardScript native library is any shared library (<InlineCode>.dll</InlineCode> on Windows, <InlineCode>.so</InlineCode> on Linux, <InlineCode>.dylib</InlineCode> on macOS) that exports the two C-linkage symbols <InlineCode>ShardLib_GetMetadata</InlineCode> and <InlineCode>ShardLib_EntryPoint</InlineCode>. It can be built from one or many C++ source files, live inside <InlineCode>ShardScript.Framework</InlineCode> or in a completely separate project, and links against the ShardScript runtime shared library using headers from <InlineCode>ShardScript/include</InlineCode>. For the full registration contract, see <InlineCode>native-library-overview.mdx</InlineCode>.
</Callout>

<Prose>
  <strong>Storage and representation.</strong> An <InlineCode>EnumSymbol</InlineCode> is a value type backed
  by a single <InlineCode>std::int64_t</InlineCode>. Its memory layout is fixed, so it is passed and returned
  by value just like other primitive value types. In a native callback you read an enum argument with{' '}
  <InlineCode>AsInteger()</InlineCode> and return an enum value with{' '}
  <InlineCode>context.Collector.FromValue(value)</InlineCode>.
</Prose>

<Prose>
  <strong>Flag semantics.</strong> Setting <InlineCode>IsFlags</InlineCode> to true only changes how the
  runtime presents the enum. The ShardScript compiler and runtime inject bitwise{' '}
  <InlineCode>{'|'}</InlineCode>, <InlineCode>{'&'}</InlineCode>, equality, and{' '}
  <InlineCode>HasFlag</InlineCode> helpers for every enum, but flag enums are expected to use power-of-two
  values so combinations compose correctly. Always include a <InlineCode>None</InlineCode> or{' '}
  <InlineCode>Zero</InlineCode> member with value <InlineCode>0</InlineCode> for the empty combination.
</Prose>

<Prose>
  <strong>Member generation.</strong> Each <InlineCode>AddValue</InlineCode> call creates a{' '}
  <InlineCode>FieldSymbol</InlineCode> attached to the enum. You do not need to register operators or methods
  yourself; the runtime binds <InlineCode>ToString</InlineCode> through <InlineCode>IPrintable</InlineCode>,
  equality, bitwise operators, and <InlineCode>HasFlag</InlineCode> automatically when the enum is finalized.
</Prose>

<Callout tone="blue">
  Keep flags values as explicit powers of two. Do not rely on auto-increment for flag enums; sequential
  values such as <InlineCode>1</InlineCode>, <InlineCode>2</InlineCode>, <InlineCode>3</InlineCode> make{' '}
  <InlineCode>HasFlag</InlineCode> return true for combinations that were never intended.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Register a plain enum and a flags enum.</strong> This native library defines a{' '}
  <InlineCode>net</InlineCode> namespace containing a status-code enum and a file-access flags enum.
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>

using namespace shard;

SHARDLIB_GETMETADATA
{
    lib.Name        = L"shard.net";
    lib.Description = L"Network and file-access enums";
    lib.Version     = L"1.0.0";
}

static ObjectInstance* open_file(const CallState& context)
{
    std::int64_t flagsValue = context.Args[0]->AsInteger();

    // Reject unknown flag bits for this example.
    std::int64_t knownBits = 1 | 2 | 4 | 8;
    if ((flagsValue & ~knownBits) != 0)
    {
        throw std::runtime_error("Unknown file flag bits");
    }

    // The real implementation would map the flags to OS open() flags here.
    return context.Collector.FromValue(0);
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> net(context, L"net");

    SymbolBuilder<EnumSymbol> httpStatus = net.AddEnum(L"HttpStatus", false, ACS_PUBLIC);
    httpStatus
        .AddValue(L"Continue", 100)
        .AddValue(L"Ok", 200)
        .AddValue(L"NotFound", 404)
        .AddValue(L"ServerError", 500);

    SymbolBuilder<EnumSymbol> fileFlags = net.AddEnum(L"FileFlags", true, ACS_PUBLIC);
    fileFlags
        .SetFlags(true)
        .AddValue(L"None", 0)
        .AddValue(L"Read", 1)
        .AddValue(L"Write", 2)
        .AddValue(L"Execute", 4)
        .AddValue(L"Shared", 8);

    net.AddMethod(L"Open", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
        .AddParameter(L"flags", fileFlags.Get())
        .SetCallback(&open_file);
}`}
  language="cpp"
  filename="net.shard.cpp"
/>

<Prose>
  ShardScript usage:
</Prose>

<CodeBlock
  code={`using stdio;
using net;

namespace demo;

public static func Main() -> void
{
    status: HttpStatus = HttpStatus.Ok;
    println(status);

    flags: FileFlags = FileFlags.Read | FileFlags.Write;

    if (flags.HasFlag(FileFlags.Read))
    {
        println("read requested");
    }

    if (flags.HasFlag(FileFlags.Execute))
    {
        println("execute requested");
    }

    handle: int = net.Open(flags);
    println(handle);
}`}
  language="csharp"
  filename="app.shard"
/>

<Prose>
  <strong>Reading an enum argument in a callback.</strong> The enum is stored as an integer, so the callback
  can inspect it directly before forwarding to native code.
</Prose>

<CodeBlock
  code={`static ObjectInstance* describe_status(const CallState& context)
{
    std::int64_t status = context.Args[0]->AsInteger();

    if (status == 200)
    {
        return context.Collector.FromValue(L"OK");
    }

    if (status == 404)
    {
        return context.Collector.FromValue(L"Not Found");
    }

    return context.Collector.FromValue(L"Other");
}`}
  language="cpp"
