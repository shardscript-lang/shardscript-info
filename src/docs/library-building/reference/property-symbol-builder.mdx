<H2>Summary</H2>

<Prose>
  The <InlineCode>PropertySymbol</InlineCode> builder registers a ShardScript property on a class, struct, or
  interface from inside a native C++ library. A property exposes one or two accessor methods — a getter, a
  setter, or both — and may optionally be backed by a compiler-managed field. Registration is fluent: call
  <InlineCode>AddProperty</InlineCode> on a type builder, then chain <InlineCode>AddGetter</InlineCode>,{' '}
  <InlineCode>AddSetter</InlineCode>, and <InlineCode>SetCallback</InlineCode> to bind native callbacks.
</Prose>

<H2>Syntax</H2>

<Prose>
  Properties are created from a <InlineCode>SymbolBuilder&lt;ClassSymbol&gt;</InlineCode>,{' '}
  <InlineCode>SymbolBuilder&lt;StructSymbol&gt;</InlineCode>, or{' '}
  <InlineCode>SymbolBuilder&lt;InterfaceSymbol&gt;</InlineCode>.
</Prose>

<CodeBlock
  code={`// Register a read-only static property.
type.AddProperty(L"Pi", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
    .AddGetter()
    .SetCallback(&get_pi);

// Register a read-write instance property.
type.AddProperty(L"Length", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
    .AddGetter().SetCallback(&get_length)
    .AddSetter().SetCallback(&set_length);

// Register a property with an auto-backing field.
SymbolBuilder<PropertySymbol> nameProp = type.AddProperty(L"Name", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);
FieldSymbol* backing = nameProp.AddBackingField().Get();

nameProp.AddGetter().SetCallback(&get_name);
nameProp.AddSetter().SetCallback(&set_name);`}
  language="cpp"
/>

<H2>Returns</H2>

<Prose>
  <InlineCode>AddProperty</InlineCode> returns a <InlineCode>PropertySymbol&amp;</InlineCode> (wrapped by the
  fluent <InlineCode>SymbolBuilder&lt;PropertySymbol&gt;</InlineCode>) so you can chain accessor registration.
  <InlineCode>AddBackingField</InlineCode> returns <InlineCode>SymbolBuilder&lt;FieldSymbol&gt;</InlineCode>; call <InlineCode>.Get()</InlineCode> to obtain the <InlineCode>FieldSymbol*</InlineCode>, which exposes{' '}
  <InlineCode>SlotIndex</InlineCode> for runtime field access. <InlineCode>SetCallback</InlineCode> returns a
  reference to the accessor builder so additional parameters may be chained, although property accessors
  typically take no explicit parameters beyond the implicit <InlineCode>this</InlineCode> and setter value.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Accessor callback never invoked</strong> — Forgetting{' '}
    <InlineCode>.SetCallback(...)</InlineCode> after <InlineCode>AddGetter</InlineCode> or{' '}
    <InlineCode>AddSetter</InlineCode> registers the accessor without a native target. Reading or writing the
    property resolves but no code runs.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Static property accessed through an instance</strong> — A property
    registered with <InlineCode>LINK_STATIC</InlineCode> must be read or written through the type name, for
    example <InlineCode>Type.Property</InlineCode>. Instance access produces a semantic error.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Instance property accessed through the type</strong> — A property
    registered with <InlineCode>LINK_INSTANCE</InlineCode> must be accessed through an object reference, for
    example <InlineCode>obj.Property</InlineCode>. Type-level access produces a semantic error.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Setter argument misalignment</strong> — For an instance setter,
    <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode> and{' '}
    <InlineCode>context.Args[1]</InlineCode> is the new value. For a static setter,{' '}
    <InlineCode>context.Args[0]</InlineCode> is the new value. Reading at the wrong index causes incorrect values
    or a crash.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Return type mismatch</strong> — A getter callback must return an
    <InlineCode>ObjectInstance*</InlineCode> whose runtime type matches the registered property type. Returning
    a differently typed value may corrupt the managed heap or cause a cast failure.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Backing field accessed before registration</strong> — The{' '}
    <InlineCode>FieldSymbol*</InlineCode> returned by <InlineCode>AddBackingField</InlineCode> is valid only after
    <InlineCode>SHARDLIB_ENTRYPOINT</InlineCode> runs. Do not read <InlineCode>SlotIndex</InlineCode> during static
    initialization.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Callout tone="blue" title="Native library shape">
  A ShardScript native library is any shared library (<InlineCode>.dll</InlineCode> on Windows, <InlineCode>.so</InlineCode> on Linux, <InlineCode>.dylib</InlineCode> on macOS) that exports the two C-linkage symbols <InlineCode>ShardLib_GetMetadata</InlineCode> and <InlineCode>ShardLib_EntryPoint</InlineCode>. It can be built from one or many C++ source files, live inside <InlineCode>ShardScript.Framework</InlineCode> or in a completely separate project, and links against the ShardScript runtime shared library using headers from <InlineCode>ShardScript/include</InlineCode>. For the full registration contract, see <InlineCode>native-library-overview.mdx</InlineCode>.
</Callout>

<Prose>
  <strong>Getter callback contract.</strong> A getter callback receives the same{' '}
  <InlineCode>shard::CallState</InlineCode> as a method. For an instance property,{' '}
  <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode>. For a static property, there is no
  implicit <InlineCode>this</InlineCode> and <InlineCode>context.Args</InlineCode> is empty. The callback must
  return a GC-owned <InlineCode>ObjectInstance*</InlineCode> produced by{' '}
  <InlineCode>context.Collector.FromValue(...)</InlineCode> or a similar allocator.
</Prose>

<Prose>
  <strong>Setter callback contract.</strong> A setter callback receives the new value as its last argument and
  must return <InlineCode>nullptr</InlineCode> (the property expression evaluates to void). For an instance
  property, <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode> and{' '}
  <InlineCode>context.Args[1]</InlineCode> is the value. For a static property,{' '}
  <InlineCode>context.Args[0]</InlineCode> is the value.
</Prose>

<Prose>
  <strong>Auto-backing fields.</strong> Call <InlineCode>AddBackingField()</InlineCode> to create a
  compiler-managed field for the property. Store the returned <InlineCode>FieldSymbol*</InlineCode> and use{' '}
  <InlineCode>{'instance->SetField(backingField->SlotIndex, value)'}</InlineCode> and{' '}
  <InlineCode>{'instance->GetField(backingField->SlotIndex)'}</InlineCode> in the getter and setter callbacks. The
  field&apos;s accessibility controls whether ShardScript code can read it directly; in most cases it should be
  <InlineCode>ACS_PRIVATE</InlineCode> so callers are forced through the property accessors.
</Prose>

<Prose>
  <strong>Static properties for constants.</strong> A read-only static property is the preferred way to expose
  library constants from a native library. It is safer than a public static field because there is no setter, and
  it matches the pattern used by libraries such as <InlineCode>shard.math</InlineCode>.
</Prose>

<Prose>
  <strong>Properties on interfaces.</strong> Interfaces can declare properties so that implementing types must
  provide matching accessors. Interface property registration uses the same <InlineCode>AddProperty</InlineCode>
  call, but without <InlineCode>SetCallback</InlineCode>; the accessor bodies are supplied by the implementing
  class or struct.
</Prose>

<Callout tone="blue">
  Prefer <InlineCode>AddBackingField</InlineCode> when the property simply stores and returns a value. Use
  explicit getter/setter callbacks when the read or write involves computation, validation, or a side effect such
  as updating a native handle.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Read-only static property.</strong> This is the most common way to expose a constant from a native
  library. There is no setter and no instance state.
</Prose>

<CodeBlock
  code={`static ObjectInstance* get_pi(const CallState& context)
{
    // No arguments for a static getter; simply return the constant value.
    return context.Collector.FromValue(3.14159);
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> math(context, L"math");

    math.AddClass(L"Math", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> mathClass)
    {
        mathClass.AddProperty(L"Pi", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddGetter()
            .SetCallback(&get_pi);
    });
}`}
  language="cpp"
  filename="math.shard.cpp"
/>

<Prose>
  ShardScript usage:
</Prose>

<CodeBlock
  code={`using stdio;
using math;

namespace demo;

public static func Main() -> void
{
    radius: double = 2.0;
    circumference: double = 2.0 * Math.Pi * radius;
    println(circumference);   // 12.56636
}`}
  language="csharp"
/>

<Prose>
  <strong>Read-write instance property with explicit callbacks.</strong> The getter computes a value from a
  private native handle; the setter validates the input before storing it.
</Prose>

<CodeBlock
  code={`static FieldSymbol* g_bufferHandle = nullptr;

static ObjectInstance* get_capacity(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* handleObj = self->GetField(g_bufferHandle->SlotIndex);
    std::int64_t handle = handleObj->AsInteger();

    // Capacity is derived from the opaque native handle value in this example.
    std::int64_t capacity = handle * 1024;

    return context.Collector.FromValue(capacity);
}

static ObjectInstance* set_capacity(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t newCapacity = context.Args[1]->AsInteger();

    if (newCapacity < 0)
    {
        // Negative capacity is not meaningful for this type.
        newCapacity = 0;
    }

    // Convert the managed capacity back into the opaque handle representation.
    std::int64_t handle = newCapacity / 1024;
    self->SetField(g_bufferHandle->SlotIndex, context.Collector.FromValue(handle));

    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> buffers(context, L"buffers");

    buffers.AddClass(L"Buffer", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> buffer)
    {
        g_bufferHandle = buffer.AddField(L"_handle", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE);

        buffer.AddProperty(L"Capacity", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
            .AddGetter().SetCallback(&get_capacity)
            .AddSetter().SetCallback(&set_capacity);
    });
}`}
  language="cpp"
  filename="buffers.shard.cpp"
/>

<Prose>
  ShardScript usage:
</Prose>

<Prose>
  <strong>Property with an auto-backing field.</strong> The compiler allocates the storage. The native callbacks
  read and write the backing field slot directly.
</Prose>

<CodeBlock
  code={`static FieldSymbol* g_nameField = nullptr;

static ObjectInstance* get_name(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* name = self->GetField(g_nameField->SlotIndex);

    if (name == nullptr || name == GarbageCollector::NullInstance)
    {
        // Return an empty string when no value has been set.
        return context.Collector.FromValue(std::wstring());
    }

    return name;
}

static ObjectInstance* set_name(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* newName = context.Args[1];

    if (newName == nullptr || newName == GarbageCollector::NullInstance)
    {
        // Treat null assignment as an empty string for this property.
        self->SetField(g_nameField->SlotIndex, context.Collector.FromValue(std::wstring()));
    }
    else
    {
        self->SetField(g_nameField->SlotIndex, newName);
    }

    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> config(context, L"config");

    config.AddClass(L"Settings", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> settings)
    {
        SymbolBuilder<PropertySymbol> nameProp = settings.AddProperty(L"Name", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);

        g_nameField = nameProp.AddBackingField();
        nameProp.AddGetter().SetCallback(&get_name);
        nameProp.AddSetter().SetCallback(&set_name);
    });
}`}
  language="cpp"
  filename="config.shard.cpp"
/>

<Prose>
  <strong>Read-write static property.</strong> Static properties can also have both a getter and a setter. They
  are useful for module-level settings that do not belong to any instance.
</Prose>

<CodeBlock
  code={`static std::int64_t g_logLevel = 0;

static ObjectInstance* get_loglevel(const CallState& context)
{
    return context.Collector.FromValue(g_logLevel);
}

static ObjectInstance* set_loglevel(const CallState& context)
{
    std::int64_t level = context.Args[0]->AsInteger();

    if (level < 0)
    {
        level = 0;
    }
    else if (level > 3)
    {
        level = 3;
    }

    g_logLevel = level;
    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> logging(context, L"logging");

    logging.AddClass(L"Log", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> logClass)
    {
        logClass.AddProperty(L"Level", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
            .AddGetter().SetCallback(&get_loglevel)
            .AddSetter().SetCallback(&set_loglevel);
    });
}`}
  language="cpp"
  filename="logging.shard.cpp"
/>

<Prose>
  ShardScript usage:
</Prose>

<CodeBlock

using logging;

namespace demo;

public static func Main() -> void

<Prose>
  <strong>Common mistake: reading the wrong argument in an instance setter.</strong> Remember that instance
  accessors always receive <InlineCode>this</InlineCode> as <InlineCode>context.Args[0]</InlineCode>.
</Prose>

<CodeBlock
  code={`buffer.AddProperty(L"Capacity", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
    .AddSetter()
    .SetCallback([](const CallState& context)
    {
        // CORRECT: this is Args[0], the new value is Args[1].
        ObjectInstance* self = context.Args[0];
        std::int64_t value = context.Args[1]->AsInteger();

        // WRONG: this would read this as the new value.
        // std::int64_t value = context.Args[0]->AsInteger();

        self->SetField(g_bufferHandle->SlotIndex, context.Collector.FromValue(value));
        return nullptr;
    });`}
  language="cpp"
/>
