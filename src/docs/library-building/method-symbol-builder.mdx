<H2>Summary</H2>

<Prose>
  <InlineCode>SymbolBuilder&lt;MethodSymbol&gt;</InlineCode> is returned by <InlineCode>AddMethod</InlineCode>.
  It exposes a chainable interface for completing the method signature and binding it to C++ code. Every
  native callback has the same signature, so the builder is the place where the ShardScript-facing contract
  (name, return type, linking, accessibility, parameters, generics) is reconciled with the C++ callback that
  runs at runtime.
</Prose>

<H2>Syntax</H2>

<Prose>
  Obtain the builder from a parent <InlineCode>SymbolBuilder</InlineCode>, then chain the configuration calls
  in any order before finally calling <InlineCode>SetCallback</InlineCode>:
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>

using namespace shard;

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> ns(context, L"mylibrary");

    SymbolBuilder<MethodSymbol> method = ns.AddMethod(
        L"Compute",
        TYPE_INT,
        LINK_STATIC,
        ACS_PUBLIC);

    method.AddParameter(L"left", TYPE_INT)
          .AddParameter(L"right", TYPE_INT)
          .SetCallback([](const CallState& context)
          {
              std::int64_t left = context.Args[0]->AsInteger();
              std::int64_t right = context.Args[1]->AsInteger();
              return context.Collector.FromValue(left + right);
          });
}`}
  language="cpp"
  filename="mylibrary.cpp"
/>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Parameter type mismatch at runtime</strong> — ShardScript resolves
    overloads by name, parameter count, and parameter types. If the registered parameter list does not match
    the call site, overload resolution fails.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Missing callback</strong> — A method registered without{' '}
    <InlineCode>SetCallback</InlineCode> resolves at compile time but does nothing when invoked.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Instance callback reads the wrong argument</strong> — For{' '}
    <InlineCode>LINK_INSTANCE</InlineCode> methods, <InlineCode>context.Args[0]</InlineCode> is{' '}
    <InlineCode>this</InlineCode>. Treating it as the first real parameter reads instance state as a parameter.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Type parameter index out of range</strong> — Reading{' '}
    <InlineCode>context.Frame-&gt;TypeArguments</InlineCode> at an index that does not correspond to an
    <InlineCode>AddTypeParameter</InlineCode> call produces undefined behavior.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Interface implementation mismatch</strong> —{' '}
    <InlineCode>IsImplementationOf</InlineCode> requires matching name, return type, parameter count, and
    parameter types. A mismatch may cause the interface to remain unimplemented.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Callout tone="blue" title="Native library shape">
  A ShardScript native library is any shared library (<InlineCode>.dll</InlineCode> on Windows, <InlineCode>.so</InlineCode> on Linux, <InlineCode>.dylib</InlineCode> on macOS) that exports the two C-linkage symbols <InlineCode>ShardLib_GetMetadata</InlineCode> and <InlineCode>ShardLib_EntryPoint</InlineCode>. It can be built from one or many C++ source files, live inside <InlineCode>ShardScript.Framework</InlineCode> or in a completely separate project, and links against the ShardScript runtime shared library using headers from <InlineCode>ShardScript/include</InlineCode>. For the full registration contract, see <InlineCode>native-library-overview.mdx</InlineCode>.
</Callout>

<Prose>
  <strong>Callback contract.</strong> Every native callback, whether for a static method, an instance method,
  a property getter, or an operator, has the same C++ signature:
</Prose>

<CodeBlock
  code={`shard::ObjectInstance* Callback(const shard::CallState& context);`}
  language="cpp"
/>

<Prose>
  The <InlineCode>context.Args</InlineCode> span contains <InlineCode>ObjectInstance*</InlineCode> pointers in
  the order the parameters were registered. For <InlineCode>LINK_INSTANCE</InlineCode> methods, the first
  element is the instance pointer. Read primitive values with helpers such as{' '}
  <InlineCode>AsInteger()</InlineCode>, <InlineCode>AsDouble()</InlineCode>, or <InlineCode>AsString()</InlineCode>,
  and box return values through <InlineCode>context.Collector.FromValue(...)</InlineCode>.
</Prose>

<Prose>
  <strong>Method-level type parameters.</strong> A type parameter added with{' '}
  <InlineCode>AddTypeParameter</InlineCode> is scoped to the method. At runtime the concrete substitution is
  available through <InlineCode>context.Frame-&gt;TypeArguments</InlineCode>, in the same order as the
  <InlineCode>AddTypeParameter</InlineCode> calls. Use the captured <InlineCode>TypeParameterSymbol*</InlineCode>
  when registering parameter types or when constructing generic types through{' '}
  <InlineCode>SymbolFactory</InlineCode>.
</Prose>

<Prose>
  <strong>Interface implementations.</strong> To implement an interface method, capture the interface method
  symbol with <InlineCode>.Get()</InlineCode> when registering the interface, then pass that pointer to{' '}
  <InlineCode>IsImplementationOf</InlineCode> on the implementing class method. The parent class must also call
  <InlineCode>Implements(interfaceSymbol)</InlineCode>.
</Prose>

<Prose>
  <strong>Global methods.</strong> Calling <InlineCode>DeclareGlobal()</InlineCode> on a namespace-level method
  makes it callable without the namespace prefix. Use sparingly to avoid polluting the global namespace.
</Prose>

<Callout tone="blue">
  Keep cross-library symbol lookups lazy. If a callback uses types from another native library, look them up
  inside an <InlineCode>EnsureSymbols</InlineCode> helper called from the callback rather than caching pointers
  during static initialization.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Namespace-level static method with multiple parameters.</strong>
</Prose>

<CodeBlock
  code={`static ObjectInstance* mylibrary_add(const CallState& context)
{
    std::int64_t left = context.Args[0]->AsInteger();
    std::int64_t right = context.Args[1]->AsInteger();
    std::int64_t sum = left + right;

    return context.Collector.FromValue(sum);
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> ns(context, L"mylibrary");

    ns.AddMethod(L"Add", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
      .AddParameter(L"left", TYPE_INT)
      .AddParameter(L"right", TYPE_INT)
      .SetCallback(&mylibrary_add);
}`}

<Prose>
  <strong>Instance method that reads <InlineCode>this</InlineCode>.</strong>
</Prose>

<CodeBlock
  code={`static FieldSymbol* g_counter_value = nullptr;

static ObjectInstance* counter_increment(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t delta = context.Args[1]->AsInteger();

    ObjectInstance* currentObj = self->GetField(g_counter_value->SlotIndex);
    std::int64_t current = currentObj->AsInteger();
    std::int64_t next = current + delta;

    self->SetField(g_counter_value->SlotIndex, context.Collector.FromValue(next));

    return context.Collector.FromValue(next);
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> ns(context, L"counters");

    ns.AddClass(L"Counter", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> cls)
    {
        g_counter_value = cls.AddField(L"_value", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE);

        cls.AddInit()
           .SetCallback([](const CallState& context)
           {
               ObjectInstance* self = context.Args[0];
               self->SetField(g_counter_value->SlotIndex, context.Collector.FromValue(0));
               return self;
           });

        cls.AddMethod(L"Increment", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
           .AddParameter(L"delta", TYPE_INT)
           .SetCallback(&counter_increment);
    });
}`}
  language="cpp"
  filename="counters.cpp"
/>

<Prose>
  <strong>Generic method with a type parameter.</strong> The method-level type parameter is used both as a
  parameter type and to allocate a correctly typed array.
</Prose>

<CodeBlock
  code={`static ObjectInstance* utils_toArray(const CallState& context)
{
    TypeSymbol* concreteT = context.Frame->TypeArguments[0];
    ObjectInstance* value = context.Args[0];

    ObjectInstance* arr = context.Collector.AllocateArray(concreteT, 1);
    arr->SetElement(0, value, context.Frame);

    return arr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolFactory factory(context.GetSemanticModel().Table.get());
    SymbolBuilder<NamespaceSymbol> ns(context, L"utils");

    ArrayTypeSymbol* byteArray = factory.Array(TYPE_BYTE);
    SymbolBuilder<MethodSymbol> toArray = ns.AddMethod(
        L"ToArray", byteArray, LINK_STATIC, ACS_PUBLIC);

    TypeParameterSymbol* t = toArray.AddTypeParameter(L"T").Get();

    toArray.AddParameter(L"value", t)
           .SetCallback(&utils_toArray);
}`}
  language="cpp"
  filename="utils.cpp"
/>

<Prose>
  <strong>Implementing an interface method.</strong> The interface method symbol is captured so the class
  method can declare itself as the concrete implementation.
</Prose>

<CodeBlock
  code={`static ObjectInstance* console_log(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    const wchar_t* message = context.Args[1]->AsString();

    // Forward the message to the host console.
    wprintf(L"%ls\\n", message);

    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> ns(context, L"logging");

    SymbolBuilder<InterfaceSymbol> iLogger = ns.AddInterface(L"ILogger", ACS_PUBLIC);
    MethodSymbol* logMethod = iLogger.AddMethod(L"Log", TYPE_VOID, LINK_INSTANCE, ACS_PUBLIC)
                                    .AddParameter(L"message", TYPE_STRING)
                                    .Get();
    iLogger.DeclareGlobal();

    ns.AddClass(L"ConsoleLogger", ACS_PUBLIC, LINK_INSTANCE, [&](SymbolBuilder<ClassSymbol> cls)
    {
        cls.Implements(iLogger.Get());

        cls.AddMethod(L"Log", TYPE_VOID, LINK_INSTANCE, ACS_PUBLIC)
           .AddParameter(L"message", TYPE_STRING)
           .IsImplementationOf(logMethod)
           .SetCallback(&console_log);
    });
}`}
  language="cpp"
  filename="logging.cpp"
/>
