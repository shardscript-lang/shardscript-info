<H2>Summary</H2>

<Prose>
  The <InlineCode>IndexatorSymbol</InlineCode> builder registers an indexer member on a ShardScript
  class, struct, or interface. Indexers let ShardScript code access instances with bracket syntax,
  such as <InlineCode>buffer[index]</InlineCode> or <InlineCode>grid[row, col]</InlineCode>. The
  fluent API defines the indexer parameters, getter, setter, and an optional backing field.
</Prose>

<H2>Syntax</H2>

<Prose>
  An indexer is created from a <InlineCode>ClassSymbol</InlineCode>,{' '}
  <InlineCode>StructSymbol</InlineCode>, or <InlineCode>InterfaceSymbol</InlineCode> builder.
</Prose>

<CodeBlock
  code={`SymbolBuilder<IndexatorSymbol> indexer = cls.AddIndexer(returnType, linking, accessibility);

indexer.AddParameter(name, type);
indexer.AddGetter().SetCallback(&getterCallback);
indexer.AddSetter().SetCallback(&setterCallback);

FieldSymbol* backingField = indexer.AddBackingField().Get();`}
  language="cpp"
/>

<H2>Returns</H2>

<Prose>
  The getter callback returns an <InlineCode>ObjectInstance*</InlineCode> that matches the indexer
  return type. Use <InlineCode>context.Collector.FromValue</InlineCode> to box primitives,{' '}
  <InlineCode>context.Collector.AllocateArray</InlineCode> for arrays, or return an existing object
  reference. The setter callback returns <InlineCode>nullptr</InlineCode> because assignment
  expressions evaluate to void.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    Throwing <InlineCode>std::runtime_error</InlineCode> from a getter or setter is converted into a
    ShardScript runtime exception. Use it for out-of-bounds access, missing keys, or invalid
    arguments.
  </Bullet>
  <Bullet>
    Calling <InlineCode>AsString()</InlineCode>, <InlineCode>AsInteger()</InlineCode>, or any
    argument accessor on <InlineCode>nullptr</InlineCode> or{' '}
    <InlineCode>GarbageCollector::NullInstance</InlineCode> crashes the host. Guard reference
    arguments first.
  </Bullet>
  <Bullet>
    Registering an indexer without a getter makes reads fail at compile time; registering without a
    setter makes assignment fail at compile time.
  </Bullet>
  <Bullet>
    A mismatch between the registered <InlineCode>SymbolLinking</InlineCode> and the call site
    prevents overload resolution from finding the indexer.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Callout tone="blue" title="Native library shape">
  A ShardScript native library is any shared library (<InlineCode>.dll</InlineCode> on Windows, <InlineCode>.so</InlineCode> on Linux, <InlineCode>.dylib</InlineCode> on macOS) that exports the two C-linkage symbols <InlineCode>ShardLib_GetMetadata</InlineCode> and <InlineCode>ShardLib_EntryPoint</InlineCode>. It can be built from one or many C++ source files, live inside <InlineCode>ShardScript.Framework</InlineCode> or in a completely separate project, and links against the ShardScript runtime shared library using headers from <InlineCode>ShardScript/include</InlineCode>. For the full registration contract, see <InlineCode>native-library-overview.mdx</InlineCode>.
</Callout>

<Prose>
  <strong>Argument layout.</strong> For an instance indexer, <InlineCode>context.Args[0]</InlineCode>{' '}
  is <InlineCode>this</InlineCode>, <InlineCode>context.Args[1]</InlineCode> is the first bracket
  parameter, and the value being assigned is the last argument for setters. For a static indexer,
  the first real parameter is <InlineCode>context.Args[0]</InlineCode> and the assigned value is the
  last argument.
</Prose>

<Prose>
  <strong>Getter and setter symmetry.</strong> An indexer may expose a getter only, a setter only,
  or both. The parameter list declared on the indexer is shared by both accessors. Call{' '}
  <InlineCode>AddParameter</InlineCode> before registering callbacks so the accessors receive the
  correct argument layout.
</Prose>

<Prose>
  <strong>Backing fields.</strong>{' '}
  <InlineCode>indexer.AddBackingField().Get()</InlineCode> creates a private field whose type equals
  the indexer return type. This is convenient for simple scalar storage, but most collection-style
  indexers store data in a manually declared array or dictionary field using{' '}
  <InlineCode>cls.AddField</InlineCode>. Store the returned <InlineCode>FieldSymbol*</InlineCode> and
  use <InlineCode>SlotIndex</InlineCode> at runtime to read or write the field.
</Prose>

<Prose>
  <strong>Indexers on interfaces.</strong> Interfaces can declare indexers with{' '}
  <InlineCode>AddIndexer</InlineCode>, <InlineCode>AddParameter</InlineCode>,{' '}
  <InlineCode>AddGetter</InlineCode>, and <InlineCode>AddSetter</InlineCode>. Implementing classes
  must register an indexer with a matching signature and parameter count.
</Prose>

<Prose>
  <strong>Generic indexers.</strong> The indexer return type and parameter types can be generic type
  parameters declared with <InlineCode>AddTypeParameter</InlineCode>. At runtime, resolve concrete
  types through <InlineCode>{'context.Frame->TypeArguments'}</InlineCode> in the same order as the
  parameters were declared.
</Prose>

<H2>Examples</H2>

<Prose>
  <strong>Example 1: single-parameter instance indexer.</strong> A <InlineCode>Buffer</InlineCode>{' '}
  class wraps a fixed-size integer array and exposes it through{' '}
  <InlineCode>buffer[index]</InlineCode>.
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>

using namespace shard;

static FieldSymbol* buffer_itemsField = nullptr;

static ObjectInstance* buffer_get_Item(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t index = context.Args[1]->AsInteger();

    ObjectInstance* items = self->GetField(buffer_itemsField->SlotIndex);

    if (index < 0 || static_cast<std::size_t>(index) >= items->GetArrayLength())
    {
        throw std::runtime_error("index is out of bounds");
    }

    return items->GetElement(static_cast<std::size_t>(index));
}

static ObjectInstance* buffer_set_Item(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t index = context.Args[1]->AsInteger();
    ObjectInstance* value = context.Args[2];

    ObjectInstance* items = self->GetField(buffer_itemsField->SlotIndex);

    if (index < 0 || static_cast<std::size_t>(index) >= items->GetArrayLength())
    {
        throw std::runtime_error("index is out of bounds");
    }

    items->SetElement(static_cast<std::size_t>(index), value);
    return nullptr;
}

static ObjectInstance* buffer_Init(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t capacity = context.Args[1]->AsInteger();

    ObjectInstance* items = context.Collector.AllocateArray(TYPE_INT, static_cast<std::size_t>(capacity));
    self->SetField(buffer_itemsField->SlotIndex, items);

    return self;
}

SHARDLIB_GETMETADATA
{
    lib.Name = L"shard.samples";
    lib.Description = L"Indexer examples";
    lib.Version = L"1.0.0";
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> samples(context, L"samples");

    samples.AddClass(L"Buffer", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> cls)
    {
        SymbolFactory factory = cls.GetFactory();
        buffer_itemsField = cls.AddField(L"_items", factory.Array(TYPE_INT), LINK_INSTANCE, ACS_PRIVATE).Get();

        cls.AddInit()
            .AddParameter(L"capacity", TYPE_INT)
            .SetCallback(&buffer_Init);

        SymbolBuilder<IndexatorSymbol> indexer = cls.AddIndexer(TYPE_INT, LINK_INSTANCE, ACS_PUBLIC);
        indexer.AddParameter(L"index", TYPE_INT);
        indexer.AddGetter().SetCallback(&buffer_get_Item);
        indexer.AddSetter().SetCallback(&buffer_set_Item);
    });
}`}
  language="cpp"
  filename="indexer-samples.shard.cpp"
/>

<Prose>
  <strong>Example 2: multi-parameter indexer.</strong> A <InlineCode>Grid</InlineCode> class stores a
  flat array and exposes two-dimensional access through <InlineCode>grid[row, col]</InlineCode>.
</Prose>

<CodeBlock
  code={`static FieldSymbol* grid_cellsField = nullptr;
static FieldSymbol* grid_columnsField = nullptr;

static ObjectInstance* grid_get_Item(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t row = context.Args[1]->AsInteger();
    std::int64_t col = context.Args[2]->AsInteger();

    ObjectInstance* cells = self->GetField(grid_cellsField->SlotIndex);
    std::int64_t columns = self->GetField(grid_columnsField->SlotIndex)->AsInteger();

    if (row < 0 || col < 0 || col >= columns)
    {
        throw std::runtime_error("index is out of bounds");
    }

    std::size_t flatIndex = static_cast<std::size_t>(row * columns + col);
    if (flatIndex >= cells->GetArrayLength())
    {
        throw std::runtime_error("index is out of bounds");
    }

    return cells->GetElement(flatIndex);
}

static ObjectInstance* grid_set_Item(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t row = context.Args[1]->AsInteger();
    std::int64_t col = context.Args[2]->AsInteger();
    ObjectInstance* value = context.Args[3];

    ObjectInstance* cells = self->GetField(grid_cellsField->SlotIndex);
    std::int64_t columns = self->GetField(grid_columnsField->SlotIndex)->AsInteger();

    if (row < 0 || col < 0 || col >= columns)
    {
        throw std::runtime_error("index is out of bounds");
    }

    std::size_t flatIndex = static_cast<std::size_t>(row * columns + col);
    if (flatIndex >= cells->GetArrayLength())
    {
        throw std::runtime_error("index is out of bounds");
    }

    cells->SetElement(flatIndex, value);
    return nullptr;
}

static ObjectInstance* grid_Init(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t rows = context.Args[1]->AsInteger();
    std::int64_t columns = context.Args[2]->AsInteger();

    std::size_t cellCount = static_cast<std::size_t>(rows * columns);
    ObjectInstance* cells = context.Collector.AllocateArray(TYPE_INT, cellCount);

    self->SetField(grid_cellsField->SlotIndex, cells);
    self->SetField(grid_columnsField->SlotIndex, context.Collector.FromValue(columns));

    return self;
}`}
  language="cpp"
  filename="grid-callbacks.cpp"
/>

<Prose>
  Register the <InlineCode>Grid</InlineCode> class and its two-parameter indexer.
</Prose>

<CodeBlock
  code={`samples.AddClass(L"Grid", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> cls)
{
    SymbolFactory factory = cls.GetFactory();

    grid_cellsField = cls.AddField(L"_cells", factory.Array(TYPE_INT), LINK_INSTANCE, ACS_PRIVATE).Get();
    grid_columnsField = cls.AddField(L"_columns", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE).Get();

    cls.AddInit()
        .AddParameter(L"rows", TYPE_INT)
        .AddParameter(L"columns", TYPE_INT)
        .SetCallback(&grid_Init);

    SymbolBuilder<IndexatorSymbol> indexer = cls.AddIndexer(TYPE_INT, LINK_INSTANCE, ACS_PUBLIC);
    indexer.AddParameter(L"row", TYPE_INT);
    indexer.AddParameter(L"column", TYPE_INT);
    indexer.AddGetter().SetCallback(&grid_get_Item);
    indexer.AddSetter().SetCallback(&grid_set_Item);
});`}
  language="cpp"
/>

<Prose>
  <strong>Example 3: backing field.</strong> A simple read-only scalar indexer that stores its default
  value in a compiler-generated backing field.
</Prose>

<CodeBlock
  code={`static ObjectInstance* scalarIndexer_get(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t key = context.Args[1]->AsInteger();

    // In a real implementation the key would select a real storage cell.
    // This example returns the backing field regardless of the key.
    ObjectInstance* value = self->GetField(scalar_backingField->SlotIndex);
    return value;
}

static ObjectInstance* scalarIndexer_set(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* value = context.Args[2];

    self->SetField(scalar_backingField->SlotIndex, value);
    return nullptr;
}

samples.AddClass(L"ScalarStore", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> cls)
{
    SymbolBuilder<IndexatorSymbol> indexer = cls.AddIndexer(TYPE_INT, LINK_INSTANCE, ACS_PUBLIC);
    indexer.AddParameter(L"key", TYPE_INT);

    scalar_backingField = indexer.AddBackingField().Get();

    indexer.AddGetter().SetCallback(&scalarIndexer_get);
    indexer.AddSetter().SetCallback(&scalarIndexer_set);
});`}
  language="cpp"
/>

<Callout tone="amber" title="Backing field vs manual field">
  <InlineCode>AddBackingField</InlineCode> creates a single field of the indexer return type. For
  collection-style indexers that store many values, declare a manual array or dictionary field with{' '}
  <InlineCode>cls.AddField</InlineCode> instead, as shown in the <InlineCode>Buffer</InlineCode> and{' '}
  <InlineCode>Grid</InlineCode> examples.
</Callout>
