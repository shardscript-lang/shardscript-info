<H2>Prerequisites</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    A C++ shared library that exports <InlineCode>ShardLib_GetMetadata</InlineCode> and{' '}
    <InlineCode>ShardLib_EntryPoint</InlineCode>. The library may contain one source file or many, and it may
    live inside <InlineCode>ShardScript.Framework</InlineCode> or in a completely separate project.
  </Bullet>
  <Bullet>
    The ShardScript runtime headers available on the include path, typically{' '}
    <InlineCode>ShardScript/include</InlineCode>.
  </Bullet>
  <Bullet>
    A linked ShardScript runtime shared library so the binary can resolve symbols such as{' '}
    <InlineCode>ObjectInstance</InlineCode>, <InlineCode>GarbageCollector</InlineCode>, and{' '}
    <InlineCode>SymbolBuilder</InlineCode>.
  </Bullet>
  <Bullet>
    Familiarity with the callback contract from <InlineCode>library-building/accessibility-and-linking</InlineCode>{' '}
    or <InlineCode>library-building/shardlib-entrypoint</InlineCode>.
  </Bullet>
</ul>

<H2>Goal</H2>

<Prose>
  Register fields on ShardScript types from native C++ code, then read and write them inside callbacks. This
  guide covers instance fields, static fields, private native handles, and the backing fields used by properties.
  By the end you will know how to use <InlineCode>FieldSymbol-&gt;SlotIndex</InlineCode> as the stable runtime key
  for object storage.
</Prose>

<H2>Step-by-Step Instructions</H2>

<Prose>
  <strong>1. Keep a global pointer to every FieldSymbol you register.</strong>
</Prose>

<Prose>
  <InlineCode>AddField</InlineCode> returns a <InlineCode>FieldSymbol*</InlineCode>. Store that pointer in a
  file-scope static variable. The field object carries a <InlineCode>SlotIndex</InlineCode>, which is the stable
  offset the runtime uses when it allocates instances of the containing type. The actual numeric value is assigned
  by the semantic model, so your code must read it from the symbol at runtime rather than hard-coding an index.
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>

using namespace shard;

// Pointers are filled in inside SHARDLIB_ENTRYPOINT and read by callbacks.
static FieldSymbol* g_sensor_idField     = nullptr;
static FieldSymbol* g_sensor_handleField = nullptr;
static FieldSymbol* g_sensor_nextIdField = nullptr;`}
  language="cpp"
/>

<Prose>
  <strong>2. Register instance fields, static fields, and private handles.</strong>
</Prose>

<Prose>
  Pass a <InlineCode>SymbolLinking</InlineCode> value and an accessibility value to{' '}
  <InlineCode>AddField</InlineCode>. <InlineCode>LINK_INSTANCE</InlineCode> stores the field per object;
  <InlineCode>LINK_STATIC</InlineCode> stores it once per type. Mark implementation-only storage such as native
  handles with <InlineCode>ACS_PRIVATE</InlineCode> so ShardScript callers cannot access them directly.
</Prose>

<CodeBlock
  code={`SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        // Per-instance state.
        g_sensor_idField = sensor.AddField(L"_id", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE);

        // Per-instance native handle. ACS_PRIVATE keeps it out of ShardScript code.
        g_sensor_handleField = sensor.AddField(L"_handle", TYPE_NINT, LINK_INSTANCE, ACS_PRIVATE);

        // Shared state: one value for the whole type.
        g_sensor_nextIdField = sensor.AddField(L"_nextId", TYPE_INT, LINK_STATIC, ACS_PRIVATE);

        sensor.AddInit()
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];

                // Read and increment the static counter.
                std::int64_t nextId = context.Collector.GetStaticField(g_sensor_nextIdField)->AsInteger();
                context.Collector.SetStaticField(g_sensor_nextIdField, context.Collector.FromValue(nextId + 1));

                // Assign the instance id and a synthetic native handle.
                self->SetField(g_sensor_idField->SlotIndex, context.Collector.FromValue(nextId));
                self->SetField(g_sensor_handleField->SlotIndex, context.Collector.FromNint(nullptr, true));

                return self;
            });

        sensor.AddMethod(L"Read", TYPE_DOUBLE, LINK_INSTANCE, ACS_PUBLIC)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* handleObj = self->GetField(g_sensor_handleField->SlotIndex);

                // In a real library the handle would be cast back to a device pointer.
                std::int64_t handle = handleObj->AsInteger();
                double sample = static_cast<double>(handle + self->GetField(g_sensor_idField->SlotIndex)->AsInteger());

                return context.Collector.FromValue(sample);
            });
    });
}`}
  language="cpp"
/>

<Callout tone="blue" title="Why keep the FieldSymbol*">
  The semantic model may reorder fields or insert hidden slots for value-type layout.{' '}
  <InlineCode>FieldSymbol-&gt;SlotIndex</InlineCode> is the only supported way to know where a field lives at
  runtime. Hard-coding slot numbers will break when the type changes.
</Callout>

<Prose>
  <strong>3. Read and write instance fields.</strong>
</Prose>

<Prose>
  Inside an instance callback, <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode>. Use
  <InlineCode>ObjectInstance::GetField(std::uint32_t)</InlineCode> and{' '}
  <InlineCode>SetField(std::uint32_t, ObjectInstance*)</InlineCode> with the field&apos;s{' '}
  <InlineCode>SlotIndex</InlineCode>. Values passed to <InlineCode>SetField</InlineCode> must be GC-owned
  instances produced by <InlineCode>context.Collector</InlineCode>.
</Prose>

<CodeBlock
  code={`static ObjectInstance* sensor_reset(const CallState& context)
{
    ObjectInstance* self = context.Args[0];

    // Read the current id; we keep it but reset the synthetic handle.
    std::int64_t id = self->GetField(g_sensor_idField->SlotIndex)->AsInteger();

    // Write a new boxed int back into the instance slot.
    self->SetField(g_sensor_idField->SlotIndex, context.Collector.FromValue(id));
    self->SetField(g_sensor_handleField->SlotIndex, context.Collector.FromNint(nullptr, true));

    return nullptr;
}`}
  language="cpp"
/>

<Prose>
  <strong>4. Read and write static fields.</strong>
</Prose>

<Prose>
  Static fields are owned by the <InlineCode>GarbageCollector</InlineCode>, not by any instance. Read them with
  <InlineCode>context.Collector.GetStaticField(FieldSymbol*)</InlineCode> and write them with{' '}
  <InlineCode>context.Collector.SetStaticField(FieldSymbol*, ObjectInstance*)</InlineCode>. Because static fields
  are shared across the application domain, guard writes carefully and prefer immutable configuration values when
  possible.
</Prose>

<CodeBlock
  code={`static ObjectInstance* sensor_resetCounter(const CallState& context)
{
    // Static method: no 'this', Args[0] is the first real parameter.
    std::int64_t value = context.Args[0]->AsInteger();

    context.Collector.SetStaticField(g_sensor_nextIdField, context.Collector.FromValue(value));

    return nullptr;
}

// Registration inside SHARDLIB_ENTRYPOINT:
// sensor.AddMethod(L"ResetCounter", TYPE_VOID, LINK_STATIC, ACS_PUBLIC)
//     .AddParameter(L"value", TYPE_INT)
//     .SetCallback(&sensor_resetCounter);`}
  language="cpp"
/>

<Prose>
  <strong>5. Store private native handles.</strong>
</Prose>

<Prose>
  A private <InlineCode>TYPE_NINT</InlineCode> field is the standard pattern for wrapping OS resources, third-party
  library objects, or any pointer that ShardScript code should not see. Register it with{' '}
  <InlineCode>ACS_PRIVATE</InlineCode> and <InlineCode>LINK_INSTANCE</InlineCode>, then read it inside methods that
  operate on the resource.
</Prose>

<CodeBlock
  code={`// Forward declaration of a callback defined elsewhere.
ObjectInstance* sensor_open(const CallState& context);

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        g_sensor_handleField = sensor.AddField(L"_handle", TYPE_NINT, LINK_INSTANCE, ACS_PRIVATE);

        sensor.AddMethod(L"Open", TYPE_VOID, LINK_INSTANCE, ACS_PUBLIC)
            .SetCallback(&sensor_open);
    });
}

static ObjectInstance* sensor_open(const CallState& context)
{
    ObjectInstance* self = context.Args[0];

    // In a real implementation this would be a real device pointer.
    void* nativeHandle = reinterpret_cast<void*>(0x1234);

    // isTransient = true: the GC must not try to free this pointer.
    self->SetField(g_sensor_handleField->SlotIndex, context.Collector.FromNint(nativeHandle, true));

    return nullptr;
}`}
  language="cpp"
/>

<Callout tone="amber" title="Handle lifetime">
  Set <InlineCode>isTransient = true</InlineCode> when the memory behind the handle is owned by the OS or by a
  third-party library. Set <InlineCode>isTransient = false</InlineCode> only when your native library allocated the
  memory and will free it explicitly, and you want the GC to participate in that cleanup.
</Callout>

<Prose>
  <strong>6. Add backing fields for properties.</strong>
</Prose>

<Prose>
  Properties registered with <InlineCode>AddProperty</InlineCode> can use a hidden field for storage. Call{' '}
  <InlineCode>AddBackingField()</InlineCode> on the property builder and keep the returned{' '}
  <InlineCode>FieldSymbol*</InlineCode>. The getter and setter callbacks then read and write that field just like
  any other instance field.
</Prose>

<CodeBlock
  code={`static FieldSymbol* g_sensor_statusBacking = nullptr;

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        SymbolBuilder<PropertySymbol> statusProp = sensor.AddProperty(L"Status", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);
        g_sensor_statusBacking = statusProp.AddBackingField().Get();

        statusProp.AddGetter()
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* status = self->GetField(g_sensor_statusBacking->SlotIndex);

                if (status == nullptr || status == GarbageCollector::NullInstance)
                {
                    return context.Collector.FromValue(std::wstring(L"unknown"));
                }

                return status;
            })
            .AddSetter()
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* value = context.Args[1];

                // The setter validates the value before storing it.
                if (value == nullptr || value == GarbageCollector::NullInstance)
                {
                    self->SetField(g_sensor_statusBacking->SlotIndex, context.Collector.FromValue(std::wstring(L"unknown")));
                }
                else
                {
                    self->SetField(g_sensor_statusBacking->SlotIndex, value);
                }

                return nullptr;
            });
    });
}`}
  language="cpp"
/>

<Callout tone="blue" title="NullInstance is a valid object">
  ShardScript <InlineCode>null</InlineCode> is represented by <InlineCode>GarbageCollector::NullInstance</InlineCode>,
  not by a C++ <InlineCode>nullptr</InlineCode>. Always check for both before dereferencing a reference-typed field.
</Callout>

<Prose>
  Build the shared library and load it from a ShardScript program. The program below creates two sensors, reads their
  ids, and exercises the property setter and getter.
</Prose>

<CodeBlock
  code={`using stdio;
using devices;

namespace demo;

public static func Main() -> void
{
    a: Sensor = new Sensor();
    b: Sensor = new Sensor();

    // Each instance receives a unique id from the static _nextId field.
    println(a.Read());
    println(b.Read());

    // Static method that resets the shared counter.
    Sensor.ResetCounter(100);

    a.Status = "active";
    println(a.Status);
}`}

<H2>Troubleshooting</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Crash when reading a field</strong> — Verify you are using the field
    symbol returned by <InlineCode>AddField</InlineCode>, not a stale pointer from a previous registration. The
    <InlineCode>SlotIndex</InlineCode> is valid only for the type on which the field was registered.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Static field value is shared across instances unexpectedly</strong>{' '}
    — That is the intended behavior. Move the data to an instance field if each object needs its own copy.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Instance callback reads the wrong value</strong> — Remember that{' '}
    <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode> for instance members. The first real
    parameter is at index <InlineCode>1</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Native handle is collected or freed by the GC</strong> — Pass the
    correct <InlineCode>isTransient</InlineCode> flag to <InlineCode>Collector.FromNint</InlineCode>. Most external
    handles should be marked transient.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Property getter returns null</strong> — A backing field starts out as
    <InlineCode>GarbageCollector::NullInstance</InlineCode>. Provide a default value in the getter or initialize the
    field in the constructor.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Static field write throws at runtime</strong> —{' '}
    <InlineCode>SetStaticField</InlineCode> rejects <InlineCode>nullptr</InlineCode>. Use{' '}
    <InlineCode>GarbageCollector::NullInstance</InlineCode> or a boxed value instead.
  </Bullet>
</ul>
