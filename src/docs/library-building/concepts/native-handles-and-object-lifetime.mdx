<Prose>
  Native libraries often sit between managed ShardScript objects and unmanaged operating-system or
  third-party resources. This article explains how to store those native resources inside instance
  fields using the <InlineCode>nint</InlineCode> type, how the garbage collector treats those
  pointers, how to keep an object alive across async boundaries with <InlineCode>ObjectRef</InlineCode>,
  and how to expose deterministic cleanup through <InlineCode>IDisposable</InlineCode>.
</Prose>

<H2>Summary</H2>

<Prose>
  A ShardScript native library can store opaque C++ pointers in instance fields by using the
  <InlineCode>TYPE_NINT</InlineCode> field type and the <InlineCode>Collector.FromNint</InlineCode>{' '}
  helper. The runtime never dereferences the stored pointer, but it does track the object that
  contains it. For types that own native handles, implement <InlineCode>IDisposable</InlineCode> in
  C++ by calling <InlineCode>cls.Implements(TRAIT_DISPOSABLE)</InlineCode> and registering a{' '}
  <InlineCode>Dispose()</InlineCode> callback that releases the handle. When an object escapes a
  synchronous callback into an async continuation, pin it with <InlineCode>ObjectRef</InlineCode> so
  the garbage collector cannot reclaim it before the continuation runs.
</Prose>

<H2>What problem it solves</H2>

<Prose>
  Wrapping OS resources in managed objects creates three lifetime problems:
</Prose>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Native handles have no meaning to the GC.</strong> A file
    descriptor, socket, or third-party context pointer is just an integer in a field as far as the
    garbage collector is concerned. The GC will not close the handle when the managed object is
    collected.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Async callbacks can outlive the current frame.</strong> If
    you pass a raw <InlineCode>ObjectInstance*</InlineCode> to a thread-pool or timer callback, the
    object may be collected before the callback executes.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Non-deterministic finalization is not enough.</strong>
    Relying on the GC to eventually release a native handle produces leaks and unpredictable
    resource exhaustion. ShardScript code expects explicit disposal through{' '}
    <InlineCode>IDisposable</InlineCode>.
  </Bullet>
</ul>

<H2>How it works</H2>

<Prose>
  <strong>Storing a native pointer.</strong> A field declared with <InlineCode>TYPE_NINT</InlineCode>{' '}
  holds a boxed <InlineCode>nint</InlineCode> value. The box is a normal GC object; the pointer it
  stores is opaque to the GC. Use <InlineCode>Collector.FromNint(ptr, isTransient)</InlineCode> to
  create the box and <InlineCode>{'field->AsNint()'}</InlineCode> to read it back. The{' '}
  <InlineCode>isTransient</InlineCode> flag tells the GC whether it should avoid freeing the box's
  backing memory; use <InlineCode>false</InlineCode> for handles whose lifetime the library manages,
  and <InlineCode>true</InlineCode> for truly external handles such as raw OS descriptors that the
  GC should never touch.
</Prose>

<Prose>
  <strong>Instance field layout.</strong> Register the field inside{' '}
  <InlineCode>SHARDLIB_ENTRYPOINT</InlineCode> and keep the returned <InlineCode>FieldSymbol*</InlineCode>.
  Its <InlineCode>SlotIndex</InlineCode> is the stable offset used at runtime. A typical disposable
  wrapper stores a <InlineCode>_handle</InlineCode> field of type <InlineCode>TYPE_NINT</InlineCode>{' '}
  and a <InlineCode>_disposed</InlineCode> field of type <InlineCode>TYPE_BOOL</InlineCode> so that
  repeated disposal is harmless.
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>
#include <shard/runtime/ObjectInstance.hpp>
#include <shard/runtime/MethodCallState.hpp>
#include <shard/runtime/GarbageCollector.hpp>

using namespace shard;

// A small native resource that the library owns and deletes.
struct TimerHandle
{
    std::int64_t IntervalMs;

    explicit TimerHandle(std::int64_t intervalMs)
        : IntervalMs(intervalMs)
    {
    }
};

static FieldSymbol* g_Timer_Disposed = nullptr;
static FieldSymbol* g_Timer_Handle = nullptr;

static ObjectInstance* timer_Init(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t intervalMs = context.Args[1]->AsInteger();

    // The library allocates the native object; the GC only sees the nint box.
    TimerHandle* handle = new TimerHandle(intervalMs);

    self->SetField(g_Timer_Handle->SlotIndex, context.Collector.FromNint(handle, false));
    self->SetField(g_Timer_Disposed->SlotIndex, context.Collector.FromValue(false));

    return self;
}

static ObjectInstance* timer_Dispose(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* disposedField = self->GetField(g_Timer_Disposed->SlotIndex);

    if (disposedField != nullptr && disposedField != GarbageCollector::NullInstance)
    {
        if (disposedField->AsBoolean())
        {
            return nullptr;
        }
    }

    ObjectInstance* handleField = self->GetField(g_Timer_Handle->SlotIndex);
    if (handleField != nullptr && handleField != GarbageCollector::NullInstance)
    {
        void* ptr = handleField->AsNint();
        if (ptr != nullptr)
        {
            delete static_cast<TimerHandle*>(ptr);
        }
    }

    // Clear the handle and mark the instance as disposed.
    self->SetField(g_Timer_Handle->SlotIndex, context.Collector.FromNint(nullptr, false));
    self->SetField(g_Timer_Disposed->SlotIndex, context.Collector.FromValue(true));

    return nullptr;
}`}
  language="cpp"
  filename="timer_callbacks.cpp"
/>

<Prose>
  <strong>Registering the disposable type.</strong> Call{' '}
  <InlineCode>cls.Implements(TRAIT_DISPOSABLE)</InlineCode> and register a public{' '}
  <InlineCode>Dispose()</InlineCode> method. The compiler can then bind resource-defers to the type
  at compile time.
</Prose>

<CodeBlock
  code={`SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> ns(context, L"demo");

    ns.AddClass(L"Timer", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> cls)
    {
        // Advertise that this type supports deterministic cleanup.
        cls.Implements(TRAIT_DISPOSABLE);

        g_Timer_Disposed = cls.AddField(L"_disposed", TYPE_BOOL, LINK_INSTANCE, ACS_PRIVATE);
        g_Timer_Handle = cls.AddField(L"_handle", TYPE_NINT, LINK_INSTANCE, ACS_PRIVATE);

        cls.AddInit()
            .AddParameter(L"intervalMs", TYPE_INT)
            .SetCallback(&timer_Init);

        cls.AddMethod(L"Dispose", TYPE_VOID, LINK_INSTANCE, ACS_PUBLIC)
            .SetCallback(&timer_Dispose);
    });
}`}
  language="cpp"
  filename="timer_registration.cpp"
/>

<Prose>
  <strong>Reading the handle safely.</strong> Always guard against{' '}
  <InlineCode>nullptr</InlineCode> and <InlineCode>GarbageCollector::NullInstance</InlineCode> before
  dereferencing a handle. A small helper keeps the check in one place.
</Prose>

<CodeBlock
  code={`static TimerHandle* GetTimerHandle(ObjectInstance* instance)
{
    ObjectInstance* handleField = instance->GetField(g_Timer_Handle->SlotIndex);
    if (handleField == nullptr || handleField == GarbageCollector::NullInstance)
    {
        return nullptr;
    }

    void* ptr = handleField->AsNint();
    if (ptr == nullptr)
    {
        return nullptr;
    }

    return static_cast<TimerHandle*>(ptr);
}`}
  language="cpp"
  filename="timer_callbacks.cpp"
/>

<Prose>
  <strong>Pinning across async boundaries.</strong> When a callback schedules work on the thread pool
  or a timer, the current frame no longer keeps the object alive. Wrap the instance in an{' '}
  <InlineCode>ObjectRef</InlineCode> to increment its reference count for the duration of the
  continuation. The destructor decrements the reference when the continuation object is destroyed.
</Prose>

<CodeBlock
  code={`static ObjectInstance* timer_DelayTick(const CallState& context) noexcept
{
    ObjectInstance* self = context.Args[0];

    return shard::DoAsync(context, [self](shard::AsyncScope async)
    {
        // Pin the instance so it survives until the delayed callback runs.
        ObjectRef pinned(self);

        async.Delay(100, [async, pinned]() mutable
        {
            ObjectInstance* instance = pinned.Instance;
            TimerHandle* handle = GetTimerHandle(instance);
            if (handle != nullptr)
            {
                // Safe to use the native handle because the object is pinned.
                handle->IntervalMs = handle->IntervalMs + 1;
            }

            async.Complete();
        });
    });
}`}
  language="cpp"
  filename="timer_callbacks.cpp"
/>

<Prose>
  <strong>Consuming the wrapper from ShardScript.</strong> Because the type implements{' '}
  <InlineCode>IDisposable</InlineCode>, ShardScript code can use the resource-defer form. The
  compiler resolves the concrete <InlineCode>Dispose()</InlineCode> method at compile time and calls
  it when the scope exits.
</Prose>

using demo;

namespace app;

public static func Main() -> void
{
    defer t: Timer = new Timer(500);
    println("timer is alive");

<H2>Key ideas</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">The GC owns returned objects, not arguments.</strong>{' '}
    Values produced by <InlineCode>Collector.FromValue</InlineCode>,{' '}
    <InlineCode>Collector.FromNint</InlineCode>, or <InlineCode>Collector.AllocateInstance</InlineCode>{' '}
    are owned by the GC and safe to return. Never delete or free argument{' '}
    <InlineCode>ObjectInstance*</InlineCode> pointers.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Use <InlineCode>TYPE_NINT</InlineCode> for opaque native
    pointers.</strong> The GC treats the field as a value type and does not follow the pointer. The
    library is responsible for allocating and freeing the underlying resource.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Choose <InlineCode>isTransient</InlineCode> carefully.</strong>{' '}
    Pass <InlineCode>false</InlineCode> when the library manages the pointed-to memory and will
    delete or free it itself. Pass <InlineCode>true</InlineCode> for raw external handles whose
    backing memory the GC must not release.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Implement <InlineCode>IDisposable</InlineCode> for native
    handle owners.</strong> Call <InlineCode>cls.Implements(TRAIT_DISPOSABLE)</InlineCode> and
    register a <InlineCode>Dispose()</InlineCode> callback. This lets ShardScript code use resource
    defers and guarantees deterministic cleanup.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Make <InlineCode>Dispose()</InlineCode> idempotent.</strong>{' '}
    Track disposal with a private bool field. If the method is called twice, either from a defer and
    a manual call or from nested ownership chains, the second call should return silently.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Pin objects that escape into async continuations.</strong>{' '}
    <InlineCode>ObjectRef</InlineCode> increments the reference counter in its constructor and
    decrements it in its destructor. Use it whenever an instance is captured by a thread-pool
    callback, timer, or libuv handle.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Null-check before dereferencing.</strong> Always compare
    argument and field values against <InlineCode>nullptr</InlineCode> and{' '}
    <InlineCode>GarbageCollector::NullInstance</InlineCode> before calling{' '}
    <InlineCode>AsNint()</InlineCode> or accessing the pointed-to object.
  </Bullet>
</ul>

<Callout tone="blue">
  <InlineCode>ObjectRef</InlineCode> is movable but not copyable. Capture it by value inside the async
  lambda and mark the lambda <InlineCode>mutable</InlineCode> so the move-only wrapper can be moved
  into the final continuation.
</Callout>

<Callout tone="amber">
  Do not store a raw <InlineCode>ObjectInstance*</InlineCode> in a native struct that outlives the
  synchronous callback. If the struct lives on another thread, use <InlineCode>ObjectRef</InlineCode>{' '}
  instead. A raw pointer does not keep the managed object alive.
</Callout>

<H2>When to use</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    A managed type wraps an OS handle, file stream, socket, third-party context, or other unmanaged
    resource.
  </Bullet>
  <Bullet>
    The native resource must be released deterministically, not whenever the GC eventually collects
    the wrapper.
  </Bullet>
  <Bullet>
    The wrapper is passed to async callbacks that run after the current native method returns.
  </Bullet>
</ul>

<H2>When not to use</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    The value is just a numeric identifier with no associated cleanup. Use <InlineCode>int</InlineCode>{' '}
    or <InlineCode>long</InlineCode> instead of <InlineCode>nint</InlineCode>.
  </Bullet>
  <Bullet>
    The resource is fully managed by another library. Do not delete a handle you do not own; store it
    as <InlineCode>isTransient = true</InlineCode> and let the owning library release it.
  </Bullet>
  <Bullet>
    The callback is synchronous and the object is only needed for the duration of the call. In that
    case the caller's frame already keeps the object alive, so <InlineCode>ObjectRef</InlineCode> is
    unnecessary.
  </Bullet>
</ul>
