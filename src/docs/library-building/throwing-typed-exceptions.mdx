<H2>Prerequisites</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    A C++20 toolchain and a built ShardScript runtime shared library.
  </Bullet>
  <Bullet>
    The ShardScript headers in <InlineCode>ShardScript/include</InlineCode> on your include path.
  </Bullet>
  <Bullet>
    Familiarity with <InlineCode>SHARDLIB_ENTRYPOINT</InlineCode>,{' '}
    <InlineCode>SymbolBuilder</InlineCode>, and the native callback contract.
  </Bullet>
  <Bullet>
    Understanding of the <InlineCode>IThrowable</InlineCode> interface and ShardScript{' '}
    <InlineCode>try</InlineCode>/<InlineCode>catch</InlineCode> semantics.
  </Bullet>
</ul>

<H2>Goal</H2>

<Prose>
  Register a custom exception class inside a native library and throw it from C++ so that ShardScript code
  can catch a specific type instead of the generic <InlineCode>RuntimeException</InlineCode>.
</Prose>

<H2>Step-by-Step Instructions</H2>

<Prose>
  <strong>1. Include the runtime exception header.</strong>
</Prose>

<Prose>
  Add <InlineCode>{'<shard/runtime/RuntimeException.hpp>'}</InlineCode> alongside the usual ShardScript
  umbrella header.
</Prose>

<CodeBlock
  code={`#include <ShardScript.hpp>
#include <shard/runtime/RuntimeException.hpp>

#include <string>

using namespace shard;`}
  language="cpp"
  filename="mylib.shard.cpp"
/>

<Prose>
  <strong>2. Declare globals for the symbol table and backing fields.</strong>
</Prose>

<Prose>
  The accessor callbacks need to read the backing fields at runtime. Store them as file-scoped globals.
</Prose>

<CodeBlock
  code={`static SymbolTable* g_symbolTable = nullptr;
static FieldSymbol* g_messageField = nullptr;
static FieldSymbol* g_stackTraceField = nullptr;
static TypeSymbol* g_myExceptionType = nullptr;`}
  language="cpp"
  filename="mylib.shard.cpp"
/>

<Prose>
  <strong>3. Implement the exception class in the library entry point.</strong>
</Prose>

<Prose>
  Register a class that implements <InlineCode>IThrowable</InlineCode>, exposes <InlineCode>message</InlineCode>
  and <InlineCode>stack_trace</InlineCode> properties, and caches their backing fields.
</Prose>

<CodeBlock
  code={`static ObjectInstance* my_exception_get_message(const CallState& context)
{
    return context.Args[0]->GetField(g_messageField);
}

static ObjectInstance* my_exception_get_stack_trace(const CallState& context)
{
    return context.Args[0]->GetField(g_stackTraceField);
}

SHARDLIB_ENTRYPOINT
{
    g_symbolTable = context.GetSemanticModel().Table.get();

    SymbolBuilder<NamespaceSymbol> ns(context, L"mylib");

    ns.AddClass(L"MyException", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> exceptionClass)
    {
        exceptionClass
            .Implements(TRAIT_THROWABLE)
            .AddInit();

        SymbolBuilder<PropertySymbol> messageProp = exceptionClass.AddProperty(
            L"message", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);
        g_messageField = messageProp.AddBackingField().Get();
        messageProp.AddGetter()
            .IsImplementationOf(TRAIT_THROWABLE_getMessage)
            .SetCallback(&my_exception_get_message);

        SymbolBuilder<PropertySymbol> stackTraceProp = exceptionClass.AddProperty(
            L"stack_trace", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);
        g_stackTraceField = stackTraceProp.AddBackingField().Get();
        stackTraceProp.AddGetter()
            .IsImplementationOf(TRAIT_THROWABLE_getStackTrace)
            .SetCallback(&my_exception_get_stack_trace);

        g_myExceptionType = exceptionClass.Get();
    });

    // Register the rest of the library here.
}`}
  language="cpp"
  filename="mylib.shard.cpp"
/>

<Prose>
  <strong>4. Add a helper that throws the typed exception.</strong>
</Prose>

<Prose>
  A small helper keeps throw sites readable and consistent.
</Prose>

<CodeBlock
  code={`static void ThrowMyException(const std::wstring& message)
{
    if (g_myExceptionType == nullptr)
    {
        throw std::runtime_error("MyException type was not registered");
    }

    throw shard::runtime_exception(message, g_myExceptionType);
}`}
  language="cpp"
  filename="mylib.shard.cpp"
/>

<Prose>
  <strong>5. Throw from a native callback.</strong>
</Prose>

<CodeBlock
  code={`static ObjectInstance* mylib_DoWork(const CallState& context)
{
    auto [value] = GetArgs<std::int64_t>(context);
    if (value < 0)
    {
        ThrowMyException(L"DoWork does not accept negative values");
    }

    return context.Collector.FromValue(value * 2);
}`}
  language="cpp"
  filename="mylib.shard.cpp"
/>

<Prose>
  <strong>6. Catch the specific type in ShardScript.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using mylib;

namespace demo;

public static func Main() -> void
{
    try
    {
        MyWorker.DoWork(-5);
    }
    catch (ex: MyException)
    {
        println("caught MyException: " + ex.message);
        println("stack trace:");
        println(ex.stack_trace);
    }
    catch (ex: RuntimeException)
    {
        println("caught generic RuntimeException");
    }
}`}
  language="csharp"
  filename="demo.shard"
/>

<H2>Verification</H2>

<Prose>
  Build the library and run the ShardScript program. You should see the typed catch clause execute and the
  <InlineCode>stack_trace</InlineCode> property should contain the managed call stack at the throw site.
</Prose>

<CodeBlock
  code={`caught MyException: DoWork does not accept negative values
stack trace:
demo.Main
demo.Program.Main`}
  language="plaintext"
  filename="expected-output.txt"
/>

<Prose>
  If you comment out the <InlineCode>catch (ex: MyException)</InlineCode> clause, the fallback{' '}
  <InlineCode>RuntimeException</InlineCode> handler should run, proving that the custom type still satisfies
  the <InlineCode>IThrowable</InlineCode> contract.
</Prose>

<H2>Troubleshooting</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Custom type is not caught.</strong> Verify that the class
    implements <InlineCode>IThrowable</InlineCode> and that both property getters are marked with{' '}
    <InlineCode>.IsImplementationOf(TRAIT_THROWABLE_getMessage)</InlineCode> and{' '}
    <InlineCode>.IsImplementationOf(TRAIT_THROWABLE_getStackTrace)</InlineCode> respectively.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Null backing field.</strong> Make sure{' '}
    <InlineCode>.AddBackingField()</InlineCode> is called before the getter is registered. The field pointer
    is needed by the VM when it writes the message and stack trace.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">VM error during mapping.</strong> The exception class must have a
    parameterless constructor. In native registration, add <InlineCode>.AddInit()</InlineCode> to the class
    builder.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Stack trace is empty.</strong> The VM populates{' '}
    <InlineCode>stack_trace</InlineCode> only for <InlineCode>IThrowable</InlineCode> instances. Ensure the
    type implements the interface and that the <InlineCode>stack_trace</InlineCode> property is backed by a
    field.
  </Bullet>
</ul>
