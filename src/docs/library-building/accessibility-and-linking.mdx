<H2>Summary</H2>

<Prose>
  When a native C++ library registers symbols through <InlineCode>SHARDLIB_ENTRYPOINT</InlineCode>, every
  namespace, type, field, method, property, indexer, and operator must declare an
  <strong>accessibility</strong> level and a <strong>linking</strong> mode. Accessibility controls
  which ShardScript code can see the symbol, and linking controls whether the symbol is bound to a type
  instance or to the type itself.
</Prose>

<H2>Syntax</H2>

<Prose>
  Accessibility and linking values are passed as positional arguments to the
  <InlineCode>SymbolBuilder</InlineCode> fluent registration API.
</Prose>

<CodeBlock
  code={`// Namespace-level symbol.
ns.AddMethod(L"Helper", TYPE_VOID, LINK_STATIC, ACS_PUBLIC)
    .SetCallback(&helper);

// Type-level symbol.
ns.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
{
    sensor.AddField(L"_handle", TYPE_NINT, LINK_INSTANCE, ACS_PRIVATE);

    sensor.AddMethod(L"Read", TYPE_DOUBLE, LINK_INSTANCE)
        .SetCallback(&sensor_read);

    sensor.AddMethod(L"Calibrate", TYPE_VOID, LINK_STATIC)
        .SetCallback(&sensor_calibrate);
});`}
  language="cpp"
/>

<DocsTable
  headers={['Value', 'Kind', 'Meaning']}
  rows={[
    [<InlineCode>ACS_PUBLIC</InlineCode>, 'Accessibility', 'Visible to any code that can reference the containing namespace.'],
    [<InlineCode>ACS_PRIVATE</InlineCode>, 'Accessibility', 'Visible only inside the declaring type.'],
    [<InlineCode>LINK_STATIC</InlineCode>, 'Linking', 'The member belongs to the type itself; no implicit <InlineCode>this</InlineCode> is passed.'],
    [<InlineCode>LINK_INSTANCE</InlineCode>, 'Linking', 'The member belongs to an instance; <InlineCode>this</InlineCode> is passed as the first argument.'],
  ]}
/>

<H2>Parameters / Arguments</H2>

<DocsTable
  headers={['Parameter', 'Applies to', 'Description']}
  rows={[
    [<InlineCode>ACS_PUBLIC</InlineCode>, 'Namespace, class, struct, interface, enum, member', 'Use for every symbol that external ShardScript code is expected to call or instantiate.'],
    [<InlineCode>ACS_PRIVATE</InlineCode>, 'Field, method, property, indexer, operator', 'Use for implementation details such as backing fields, helper methods, and native handles that must not be touched by callers.'],
    [<InlineCode>LINK_STATIC</InlineCode>, 'Method, property, indexer, operator, constructor', 'Use when the member does not read or write per-instance state. Static constructors (<InlineCode>AddInit</InlineCode>) also use this value.'],
    [<InlineCode>LINK_INSTANCE</InlineCode>, 'Class, struct, field, method, property, indexer, operator', 'Use when the member operates on a specific instance. This is the required linking mode for instance fields and instance constructors.'],
  ]}
/>

<H2>Returns</H2>

<Prose>
  Accessibility and linking values are not expressions and do not return a value. They are compile-time
  registration flags that the semantic model stores on the resulting <InlineCode>Symbol</InlineCode>. At
  runtime the VM uses them to decide whether a call is allowed and whether to pass an implicit{' '}
  <InlineCode>this</InlineCode> argument.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Symbol not found at compile time</strong> — A member registered
    with <InlineCode>ACS_PRIVATE</InlineCode> cannot be referenced from ShardScript code outside the declaring
    type.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Static called on an instance, or instance called on a type</strong>{' '}
    — A method registered with <InlineCode>LINK_STATIC</InlineCode> must be invoked as{' '}
    <InlineCode>Type.Method()</InlineCode>. A method registered with <InlineCode>LINK_INSTANCE</InlineCode>{' '}
    must be invoked as <InlineCode>instance.Method()</InlineCode>. Mismatching the linking mode produces a
    semantic error.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Instance member in a static type</strong> — A class registered
    without instance linking on its members but called as an instance type, or a static class that declares
    instance members, fails validation.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary"><InlineCode>this</InlineCode> argument misalignment</strong> — For
    an instance callback, <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode>. Treating
    it as the first real parameter causes incorrect reads or a crash.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Callback never invoked</strong> — Forgetting{' '}
    <InlineCode>.SetCallback(...)</InlineCode> leaves the symbol registered but without a native target. The
    call resolves but no code runs.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>Accessibility boundaries.</strong> <InlineCode>ACS_PUBLIC</InlineCode> is the only value that makes
  a symbol visible to code outside the declaring type. If you intend a type or member to be consumed by
  ShardScript programs, mark it <InlineCode>ACS_PUBLIC</InlineCode>. Implementation helpers, backing fields,
  and native handles should be marked <InlineCode>ACS_PRIVATE</InlineCode> so they cannot be referenced by
  callers.
</Prose>

<Prose>
  <strong>Linking determines the call contract.</strong> <InlineCode>LINK_INSTANCE</InlineCode> means the
  runtime will pass the instance pointer as <InlineCode>context.Args[0]</InlineCode>. Real parameters start at
  index <InlineCode>1</InlineCode>. <InlineCode>LINK_STATIC</InlineCode> means there is no implicit{' '}
  <InlineCode>this</InlineCode>; the first real parameter is at index <InlineCode>0</InlineCode>. The same
  callback signature is used for both modes, so the callback must read arguments at the correct offsets.
</Prose>

<Prose>
  <strong>Statics for utility types.</strong> A class that contains only static members, such as{' '}
  <InlineCode>shard.math</InlineCode>, is registered with static methods and no instance fields. Constants and
  factory methods that do not depend on object state should also use <InlineCode>LINK_STATIC</InlineCode>.
</Prose>

<Prose>
  <strong>Instance state and native handles.</strong> Types that wrap OS resources, such as file streams or
  sockets, store native handles in <InlineCode>LINK_INSTANCE</InlineCode> fields with{' '}
  <InlineCode>ACS_PRIVATE</InlineCode> accessibility. The callback then reads the handle from{' '}
  <InlineCode>context.Args[0]</InlineCode> and performs the operation without exposing the handle to
  ShardScript callers.
</Prose>

<Prose>
  <strong>Constructors and initializers.</strong> <InlineCode>AddInit</InlineCode> is the registration method
  for constructors. It is registered with <InlineCode>LINK_STATIC</InlineCode> because the runtime calls it to
  initialize a freshly allocated instance; the callback receives the new instance as{' '}
  <InlineCode>context.Args[0]</InlineCode> and must return that same instance.
</Prose>

<Callout tone="blue">
  Choose <InlineCode>LINK_STATIC</InlineCode> for anything that does not need <InlineCode>this</InlineCode>,
  and <InlineCode>ACS_PUBLIC</InlineCode> for anything that callers outside the library must see. The most
  common native-library bug is a mismatch between the registered linking mode and the call site.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Public static utility class.</strong> This pattern is common for libraries such as{' '}
  <InlineCode>shard.math</InlineCode>: only static methods and static properties are exposed.
</Prose>

<CodeBlock
  code={`SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> math(context, L"math");

    math.AddClass(L"Math", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> mathClass)
    {
        mathClass.AddMethod(L"Abs", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"value", TYPE_INT)
            .SetCallback([](const CallState& context)
            {
                std::int64_t value = context.Args[0]->AsInteger();

                if (value < 0)
                {
                    value = -value;
                }

                return context.Collector.FromValue(value);
            });
    });
}`}
  language="cpp"
/>

<Prose>
  ShardScript usage:
</Prose>

<CodeBlock
  code={`using stdio;
using math;

namespace demo;

public static func Main() -> void
{
    result: int = Math.Abs(-7);
    println(result);   // 7
}`}
  language="csharp"
/>

<Prose>
  <strong>Public instance type with a private native handle.</strong> The handle is stored in an instance
  field; callers use instance methods.
</Prose>

<CodeBlock
  code={`static FieldSymbol* g_sensorHandle = nullptr;

static ObjectInstance* sensor_read(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* handleObj = self->GetField(g_sensorHandle->SlotIndex);
    std::int64_t handle = handleObj->AsInteger();

    // Read from the hardware represented by the opaque handle.
    double sample = static_cast<double>(handle) * 0.125;

    return context.Collector.FromValue(sample);
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> sensors(context, L"sensors");

    sensors.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        g_sensorHandle = sensor.AddField(L"_handle", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE);

        sensor.AddInit()
            .AddParameter(L"id", TYPE_INT)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* id = context.Args[1];
                self->SetField(g_sensorHandle->SlotIndex, id);
                return self;
            });

        sensor.AddMethod(L"Read", TYPE_DOUBLE, LINK_INSTANCE, ACS_PUBLIC)
            .SetCallback(&sensor_read);

        sensor.AddMethod(L"Count", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
            .SetCallback([](const CallState& context)
            {
                // Static helper: no instance state is accessed.
                return context.Collector.FromValue(0);
            });
    });
}`}
  language="cpp"
/>

<Prose>
  ShardScript usage:
</Prose>

<CodeBlock
  code={`using stdio;
using sensors;

namespace demo;

public static func Main() -> void
{
    s: Sensor = new Sensor(1);
    sample: double = s.Read();
    println(sample);

    total: int = Sensor.Count();
    println(total);
}`}
  language="csharp"
/>

<Prose>
  <strong>Private helper inside a type.</strong> A private static method is visible only to other members of
  the same type. Namespace-level helpers cannot be hidden from the rest of the library, so keep sensitive
  implementation details inside a private type.
</Prose>

<CodeBlock
  code={`static ObjectInstance* ensure_buffer_size(const CallState& context)
{
    ObjectInstance* buffer = context.Args[0];
    std::int64_t required = context.Args[1]->AsInteger();
    std::size_t current = buffer->GetArrayLength();

    if (current < static_cast<std::size_t>(required))
    {
        ObjectInstance* replacement = context.Collector.AllocateArray(TYPE_BYTE, required);
        return replacement;
    }

    return buffer;
}

SHARDLIB_ENTRYPOINT
{
    SymbolFactory factory(context.GetSemanticModel().Table.get());
    SymbolBuilder<NamespaceSymbol> buffers(context, L"buffers");

    buffers.AddClass(L"BufferHelpers", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> helpers)
    {
        ArrayTypeSymbol* byteArray = factory.Array(TYPE_BYTE);
        helpers.AddMethod(L"EnsureBufferSize", byteArray, LINK_STATIC, ACS_PRIVATE)
            .AddParameter(L"buffer", byteArray)
            .AddParameter(L"required", TYPE_INT)
            .SetCallback(&ensure_buffer_size);
    });
}`}
  language="cpp"
/>

<Prose>
  <strong>Common mistake: instance callback reading the wrong argument index.</strong> Because{' '}
  <InlineCode>context.Args[0]</InlineCode> is <InlineCode>this</InlineCode>, the first real parameter is at
  index <InlineCode>1</InlineCode>.
</Prose>

<CodeBlock
  code={`sensor.AddMethod(L"Move", TYPE_VOID, LINK_INSTANCE, ACS_PUBLIC)
    .AddParameter(L"distance", TYPE_DOUBLE)
    .SetCallback([](const CallState& context)
    {
        // CORRECT: this is Args[0], distance is Args[1].
        ObjectInstance* self = context.Args[0];
        double distance = context.Args[1]->AsDouble();

        // WRONG: this would read this as a double.
        // double distance = context.Args[0]->AsDouble();

        self->SetField(g_positionField->SlotIndex, context.Collector.FromValue(distance));
        return nullptr;
    });`}
  language="cpp"
/>

<Prose>
  <strong>Common mistake: registering a static member with instance linking.</strong> If a method does not
  use <InlineCode>this</InlineCode>, register it with <InlineCode>LINK_STATIC</InlineCode> and call it through
  the type name.
</Prose>

<CodeBlock
  code={`using stdio;
using sensors;

namespace demo;

public static func Main() -> void
{
    // CORRECT: Count is static, so it is invoked on the type.
    total: int = Sensor.Count();
    println(total);

    // WRONG: Count is not an instance member.
    // s: Sensor = new Sensor(1);
    // total = s.Count();
}`}
  language="csharp"
/>
