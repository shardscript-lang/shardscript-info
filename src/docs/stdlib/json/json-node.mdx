<H2>Summary</H2>

<Prose>
  <InlineCode>JsonNode</InlineCode> is the mutable DOM (Document Object Model) representation of a
  JSON value in <InlineCode>shard.json</InlineCode>. It lets you parse arbitrary JSON text,
  inspect its structure, navigate objects and arrays by key or index, mutate values in-place,
  and write the result back to a JSON string without declaring a typed model.
</Prose>

<H2>Syntax</H2>

<Prose>
  All <InlineCode>JsonNode</InlineCode> members live in the <InlineCode>json</InlineCode> namespace.
  The class is a regular reference type; instances wrap a native <InlineCode>JsonDom</InlineCode>{' '}
  tree stored in the private <InlineCode>_handle</InlineCode> field.
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public static func Main() -> void
{
    // Parse a JSON text into a DOM tree.
    root: JsonNode = JsonNode.Parse("{\"name\":\"Ada\",\"tags\":[\"math\",\"compute\"]}");

    // Navigate and extract values.
    name: string = root.Get("name").AsString();
    firstTag: string = root.Get("tags").At(0).AsString();

    // Mutate the DOM and serialize it back to text.
    root.Set("age", JsonNode.Parse("36"));
    println(root.ToString());
}`}

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Invalid JSON</strong> —{' '}
    <InlineCode>JsonNode.Parse</InlineCode> throws a runtime error if the input is malformed,
    contains trailing characters, has unterminated strings, or uses invalid escape sequences.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Set on null node</strong> — Calling{' '}
    <InlineCode>Set</InlineCode> on a null/missing node throws because there is no DOM tree to mutate.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Add on null node</strong> — Calling{' '}
    <InlineCode>Add</InlineCode> on a null/missing node throws for the same reason.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Nesting depth exceeded</strong> — Both parsing and
    serialization enforce a maximum depth of 512 levels to prevent stack overflow on deeply
    nested or cyclic structures.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Non-finite number</strong> — Serializing a{' '}
    <InlineCode>double</InlineCode> that is NaN or infinity throws because these values have no
    valid JSON representation.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>Type inspection.</strong> Always inspect a node's kind before assuming its shape.
  <InlineCode>Kind</InlineCode> returns a <InlineCode>JsonNodeKind</InlineCode> value, while the
  convenience predicates <InlineCode>IsNull</InlineCode>, <InlineCode>IsObject</InlineCode>, and{' '}
  <InlineCode>IsArray</InlineCode> cover the most common checks. A missing key or out-of-bounds
  access returns the VM's <InlineCode>null</InlineCode> instance, so{' '}
  <InlineCode>node.Get("missing").IsNull</InlineCode> is true.
</Prose>

<Prose>
  <strong>Coercive extraction.</strong> The <InlineCode>As*</InlineCode> methods are forgiving:
  they return zero-like defaults for mismatched kinds rather than throwing. This makes them useful
  for loosely-structured data, but it also means typos in keys silently produce 0 or empty strings.
  Use <InlineCode>Contains</InlineCode> or <InlineCode>Kind</InlineCode> when you need to distinguish
  between missing, null, and present-but-zero values.
</Prose>

<Prose>
  <strong>Object navigation and mutation.</strong> <InlineCode>Get</InlineCode> performs a linear
  scan over object members, so lookups are <InlineCode>O(n)</InlineCode> in the number of keys.
  <InlineCode>Set</InlineCode> overwrites an existing key or appends a new one. If the receiver is
  not an object, <InlineCode>Set</InlineCode> silently converts it into one by replacing its kind.
  This lets you turn a parsed scalar into a container, but it discards the old value.
</Prose>

<Prose>
  <strong>Array navigation and mutation.</strong> <InlineCode>At</InlineCode> checks the bounds and
  returns null for invalid indices or non-array receivers. <InlineCode>Add</InlineCode> appends to
  the end; like <InlineCode>Set</InlineCode>, it converts a non-array receiver into an array.
  <InlineCode>Length()</InlineCode> reports the element count for arrays and 0 for everything else.
</Prose>

<Prose>
  <strong>Stringify behavior.</strong> <InlineCode>ToString()</InlineCode> emits compact JSON with
  no extra whitespace. Numbers are written with the shortest round-trip-safe representation.
  Strings are escaped according to the JSON spec, including Unicode surrogate pairs and control
  characters. Because <InlineCode>JsonNode</InlineCode> implements <InlineCode>IPrintable</InlineCode>,
  you can pass a node directly to <InlineCode>println</InlineCode>.
</Prose>

<Prose>
  <strong>Shared native DOM.</strong> <InlineCode>JsonNode</InlineCode> and{' '}
  <InlineCode>JsonSerializer</InlineCode> share the same internal <InlineCode>JsonDom</InlineCode>{' '}
  tree. <InlineCode>JsonNode.Parse</InlineCode> builds the tree with the same recursive-descent
  parser used by typed deserialization, and <InlineCode>ToString()</InlineCode> uses the same
  writer as <InlineCode>JsonSerializer.Serialize</InlineCode>.
</Prose>

<Prose>
  <strong>Lifetime.</strong> The C++ <InlineCode>JsonDom</InlineCode> nodes are allocated with{' '}
  <InlineCode>new</InlineCode> and are never freed; there is no destructor. Each parsed or mutated
  node lives for the lifetime of the process. This is acceptable for configuration files and
  bounded API payloads, but avoid creating large numbers of intermediate nodes in long-running
  loops or stream processors.
</Prose>

<Prose>
  <strong>Access operator.</strong> <InlineCode>JsonNode</InlineCode> overloads the delimiter operator
  so object members can be read with dot syntax: <InlineCode>node.Name</InlineCode> is equivalent to{' '}
  <InlineCode>node.Get("Name")</InlineCode>. The identifier after the dot is passed as the key name.
  If the receiver is not an object or the key is missing, the expression returns a null node. This
  works for any identifier that is a valid ShardScript token, including identifiers that would
  otherwise collide with method names.
</Prose>

<Prose>
  <strong>Cast operators.</strong> <InlineCode>JsonNode</InlineCode> provides static{' '}
  <InlineCode>as</InlineCode> overloads for <InlineCode>int</InlineCode>,{' '}
  <InlineCode>double</InlineCode>, <InlineCode>bool</InlineCode>, <InlineCode>string</InlineCode>, and{' '}
  <InlineCode>byte</InlineCode>. <InlineCode>node as int</InlineCode> behaves like{' '}
  <InlineCode>node.AsInt()</InlineCode>; the other casts mirror their corresponding{' '}
  <InlineCode>As*</InlineCode> methods. These casts are convenient when extracting scalar values from
  a dotted path, but they are forgiving and return zero-like defaults for mismatched or missing
  values.
</Prose>

<Callout tone="amber" title="Planned features">
  The current API provides the core DOM operations used in the test suite. Additional helpers such
  as <InlineCode>Remove(key)</InlineCode>, <InlineCode>RemoveAt(index)</InlineCode>, value-typed
  constructors (for example <InlineCode>JsonNode.FromInt</InlineCode>), deep cloning, and formatted
  (pretty-printed) output are planned but not yet implemented. Use <InlineCode>Parse</InlineCode>{' '}
  to construct primitive nodes today.
</Callout>

  <strong>Parsing and inspecting a mixed document.</strong>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public static func Main() -> void
{
    text: string = "{\"a\":[1,2,3],\"b\":\"hi\",\"c\":null,\"d\":true,\"e\":-2.5e1}";
    root: JsonNode = JsonNode.Parse(text);

    println(root.Kind);                     // Object
    println(root.Get("b").AsString());      // hi
    println(root.Get("a").Length());        // 3
    println(root.Get("a").At(2).AsInt());   // 3
    println(root.Get("c").IsNull);          // true
    println(root.Get("d").AsBool());        // true
    println(root.Get("e").AsDouble());      // -25.0
    println(root.Contains("a"));            // true
    println(root.Contains("z"));            // false
}`}

<Prose>
  <strong>Mutating and building JSON documents.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public static func Main() -> void
{
    mut: JsonNode = JsonNode.Parse("{\"x\":1}");

    // Add a new key with a parsed value node.
    mut.Set("y", JsonNode.Parse("\"added\""));

    // Convert the existing number at "x" into an object containing "nested".
    mut.Get("x").Set("nested", JsonNode.Parse("42"));

    // Build a fresh array and attach it.
    scores: JsonNode = JsonNode.Parse("[]");
    scores.Add(JsonNode.Parse("95"));
    scores.Add(JsonNode.Parse("87"));
    mut.Set("scores", scores);

    println(mut.ToString());
    // Output: {"x":{"nested":42},"y":"added","scores":[95,87]}
}`}

<Prose>
  <strong>Defensive access and common mistakes.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public static func Main() -> void
{
    root: JsonNode = JsonNode.Parse("{\"value\":0,\"missing\":null}");

    // Mistake: AsInt returns 0 both for the literal 0 and for missing keys.
    zero: int = root.Get("value").AsInt();
    alsoZero: int = root.Get("doesNotExist").AsInt();
    println(zero);        // 0
    println(alsoZero);    // 0

    // Correct: check existence and kind before extraction.
    target: JsonNode = root.Get("value");
    if (!target.IsNull && target.Kind == JsonNodeKind.Number)
    {
        println("value is present: " + target.AsInt());
    }

    // Check for null vs missing with IsNull.
    if (root.Get("missing").IsNull)
    {
        println("missing is null or absent");
    }

    // Array bounds return null nodes, not errors.
    arr: JsonNode = JsonNode.Parse("[10,20]");
    bad: JsonNode = arr.At(99);
    println(bad.IsNull);      // true
}`}

<Prose>
  <strong>Dot-access and cast shortcuts.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public static func Main() -> void
{
    node: JsonNode = JsonNode.Parse("{\"Name\":\"Ada\",\"Age\":36,\"Height\":1.68,\"Active\":true,\"Missing\":null}");

    // Dot access returns a JsonNode for the named member.
    println(node.Name as string);      // Ada
    println(node.Age as int);          // 36
    println(node.Height as double);    // 1.68
    println(node.Active as bool);      // true

    // Missing members produce a null node rather than throwing.
    println(node.Missing.IsNull);      // true
    println(node.Missing as int);      // 0

    // Array elements still use At(index).
    arr: JsonNode = JsonNode.Parse("[10,20,30]");
    println(arr.At(1).AsInt());        // 20

    // Byte casts are also supported.
    println(node.Age as byte);         // 36
}`}

<Prose>
  <strong>Round-tripping with typed serialization.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public class Person
{
    public Name: string;
    public Age: int;
}

public static func Main() -> void
{
    raw: string = "{\"Name\":\"Grace\",\"Age\":28}";

    // Use JsonNode for structural validation, then deserialize the inner object.
    root: JsonNode = JsonNode.Parse(raw);

    if (root.Contains("Name") && root.Contains("Age"))
    {
        person: Person = JsonSerializer.Deserialize<Person>(root.ToString());
        println(person.Name + " is " + person.Age);
    }
    else
    {
        println("schema mismatch");
    }
}`}

<Callout tone="blue">
  <InlineCode>AsString()</InlineCode> on a non-string node returns the JSON text of that node, not
  an empty string. For example, <InlineCode>JsonNode.Parse("42").AsString()</InlineCode> returns
  the string <InlineCode>&quot;42&quot;</InlineCode> and{' '}
  <InlineCode>JsonNode.Parse("[1,2]").AsString()</InlineCode> returns the string
  <InlineCode>&quot;[1,2]&quot;</InlineCode>. Use <InlineCode>Kind</InlineCode> first if you need
  to distinguish strings from other types.
</Callout>
