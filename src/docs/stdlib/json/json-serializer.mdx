<H2>Summary</H2>

<Prose>
  The <InlineCode>shard.json</InlineCode> library exposes a static class{' '}
  <InlineCode>JsonSerializer</InlineCode> in the <InlineCode>json</InlineCode> namespace. Its two
  generic methods — <InlineCode>Serialize&lt;T&gt;</InlineCode> and{' '}
  <InlineCode>Deserialize&lt;T&gt;</InlineCode> — convert between ShardScript objects and standard
  JSON text by reflecting over public fields. The serializer emits compact, RFC 8259–compatible
  output; the deserializer reconstructs a typed object graph from JSON keys and values.
</Prose>

<H2>Syntax</H2>

<Prose>
  Both methods are static and generic. The type argument names the concrete ShardScript type to
  serialize from or deserialize into.
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public static func Main() -> void
{
    // Serialize a primitive value to JSON text.
    text: string = JsonSerializer.Serialize<int>(42);
    println(text);   // 42

    // Deserialize the text back to the original type.
    value: int = JsonSerializer.Deserialize<int>(text);
    println(value);  // 42
}`}

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Missing type argument</strong> —{' '}
    <InlineCode>Deserialize&lt;T&gt;</InlineCode> requires an explicit type argument. Omitting it
    raises <InlineCode>"JSON: Deserialize requires a type argument, e.g. Deserialize&lt;Person&gt;(...)"</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Null text argument</strong> — Passing{' '}
    <InlineCode>null</InlineCode> to <InlineCode>Deserialize&lt;T&gt;</InlineCode> raises{' '}
    <InlineCode>"JSON: Deserialize text is null"</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Malformed JSON</strong> — Missing quotes, trailing
    commas, unterminated strings, or unexpected characters raise{' '}
    <InlineCode>RuntimeException</InlineCode> with a message that includes the parse position.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Root kind mismatch</strong> — Deserializing a JSON
    number into a class, or a JSON object into an array, raises{' '}
    <InlineCode>"JSON: expected object"</InlineCode> or{' '}
    <InlineCode>"JSON: expected array"</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Non-finite double</strong> — Serializing{' '}
    <InlineCode>double.PositiveInfinity</InlineCode>, <InlineCode>double.NegativeInfinity</InlineCode>,
    or <InlineCode>double.NaN</InlineCode> raises{' '}
    <InlineCode>"JSON: cannot serialize non-finite number"</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Nesting depth exceeded</strong> — Object graphs deeper
    than 512 levels raise{' '}
    <InlineCode>"JSON: nesting depth exceeded (possible cycle)"</InlineCode>. This is a depth guard,
    not a true cycle detector.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>Supported type mapping.</strong> The serializer and deserializer recognize a fixed set of
  ShardScript types and map them to JSON as follows:
</Prose>

<DocsTable
  headers={['ShardScript Type', 'JSON Type', 'Notes']}
  rows={[
    ['int', 'Number', 'Integer value, serialized without a decimal point.'],
    ['double', 'Number', 'Floating-point value, formatted for round-trip safety.'],
    ['bool', 'Boolean', 'Literal true or false.'],
    ['char', 'String', 'A single-character string.'],
    ['string', 'String', 'UTF-16 text; control characters and non-ASCII code points are escaped.'],
    ['enum', 'Number', 'Serialized as the underlying integer value of the enumerator.'],
    ['T[]', 'Array', 'Elements are encoded recursively; null elements become JSON null.'],
    ['class / struct', 'Object', 'Each public field becomes a key-value pair.'],
    ['null reference', 'null', 'Serialized as the JSON literal null.'],
  ]}
/>

<Callout tone="blue">
  Only <strong className="text-text-primary">public fields</strong> are serialized. Private and
  static fields are skipped. The deserializer also populates only public fields; properties,
  methods, and constructors other than the parameterless allocator are not involved.
</Callout>

<Prose>
  <strong>Serialization rules.</strong> <InlineCode>Serialize&lt;T&gt;</InlineCode> walks the object
  graph recursively and emits one JSON value. Class and struct instances become JSON objects whose
  keys match field names exactly. Arrays become JSON arrays in element order. Null references,
  including array elements and object fields, become the JSON literal <InlineCode>null</InlineCode>.
  Enum values are written as their integer backing value, not as a string name.
</Prose>

<Prose>
  <strong>Deserialization rules.</strong> <InlineCode>Deserialize&lt;T&gt;</InlineCode> allocates a
  new instance of <InlineCode>T</InlineCode> and fills its public fields by matching JSON keys to
  field names. The matching is case-sensitive and exact.
</Prose>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Missing keys.</strong> Fields without a matching JSON key
    keep their default values: <InlineCode>0</InlineCode> for integers,{' '}
    <InlineCode>0.0</InlineCode> for doubles, <InlineCode>false</InlineCode> for bools,{' '}
    <InlineCode>""</InlineCode> for strings, and <InlineCode>null</InlineCode> for reference types.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Extra keys.</strong> JSON keys that do not match any field
    on the target type are silently ignored.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Primitive coercion.</strong> When deserializing into a
    primitive or enum field, the JSON value is coerced: numbers are truncated or parsed, strings
    that represent numbers are parsed, and booleans map to <InlineCode>1</InlineCode> /{' '}
    <InlineCode>0</InlineCode>. Unparseable strings yield the default value instead of throwing.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Reference nulls.</strong> A JSON null assigned to a
    reference-type field leaves that field as <InlineCode>null</InlineCode>. Value-type fields are
    not affected by JSON null.
  </Bullet>
</ul>

<Prose>
  <strong>Cycle and depth protection.</strong> Serialization keeps a recursion counter that
  increments for each nested object or array. If the depth exceeds 512, the serializer aborts with a
  <InlineCode>RuntimeException</InlineCode>. Cyclic references therefore cause a depth error rather
  than an infinite loop. There is no reference-identity deduplication: the same object referenced
  from two places is encoded twice.
</Prose>

<Prose>
  <strong>Number formatting.</strong> Integers are written with no fractional component. Doubles are
  written with the shortest round-trip format: trailing zeros are removed, but enough precision is
  preserved so that parsing the text back yields the same <InlineCode>double</InlineCode> value.
  Non-finite floating-point values cannot be represented in JSON and raise an exception.
</Prose>

<Callout tone="amber" title="Formatting options not implemented">
  <InlineCode>JsonSerializer</InlineCode> always produces compact JSON with no whitespace,
  indentation, or line breaks. Pretty-printing, custom naming policies (such as camelCase), and
  per-field ignore attributes are not currently exposed. Use <InlineCode>JsonNode</InlineCode> for
  scenarios that require a formatted or custom-shaped document.
</Callout>

<Prose>
  <strong>Unsupported types.</strong> Interfaces, delegates, and open generic types are not
  serialized. Attempting to serialize a field of one of these types produces{' '}
  <InlineCode>null</InlineCode> in the output. Dictionaries and other collection objects are treated
  as plain classes, so only their public fields are encoded; their elements are not enumerated.
</Prose>

<H2>Examples</H2>

<Prose>
  <strong>Serializing and deserializing a class graph.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public enum Status
{
    Active,
    Inactive
}

public class Address
{
    public City: string;
    public Zip: string;
}

public class Person
{
    public Name: string;
    public Age: int;
    public Height: double;
    public IsMember: bool;
    public State: Status;
    public Tags: string[];
    public Home: Address;
}

public static func Main() -> void
{
    person: Person = new Person();
    person.Name = "Ada Lovelace";
    person.Age = 36;
    person.Height = 1.68;
    person.IsMember = true;
    person.State = Status.Active;
    person.Tags = ["math", "compute"];

    home: Address = new Address();
    home.City = "London";
    home.Zip = "SW1";
    person.Home = home;

    text: string = JsonSerializer.Serialize<Person>(person);
    println(text);
    // {"Name":"Ada Lovelace","Age":36,"Height":1.68,"IsMember":true,"State":0,"Tags":["math","compute"],"Home":{"City":"London","Zip":"SW1"}}

    copy: Person = JsonSerializer.Deserialize<Person>(text);
    println(copy.Name);        // Ada Lovelace
    println(copy.Age);         // 36
    println(copy.Height);      // 1.68
    println(copy.Home.City);   // London

    foreach (tag in copy.Tags)
    {
        println(tag);          // math, compute
    }
}`}

  <strong>Handling malformed JSON and root-kind mismatches.</strong>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public class Point
{
    public X: int;
    public Y: int;
}

public static func Main() -> void
{
    // Keys must be quoted strings in JSON.
    badObject: string = "{X:1,Y:2}";

    try
    {
        point1: Point = JsonSerializer.Deserialize<Point>(badObject);
        println(point1.X);
    }
    catch (ex: RuntimeException)
    {
        println("parse failed: keys must be quoted");
    }

    // An array root cannot be deserialized into a class.
    badRoot: string = "[1,2]";

    try
    {
        point2: Point = JsonSerializer.Deserialize<Point>(badRoot);
        println(point2.X);
    }
    catch (ex: RuntimeException)
    {
        println("root kind mismatch: expected object");
    }
}`}

<Prose>
  <strong>Common mistake: serializing private fields.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using json;

namespace demo;

public class Account
{
    // Public fields are visible to the serializer.
    public Owner: string;

    // Private fields are ignored, even if they are initialized.
    private Pin: int;

    public init(owner: string, pin: int)
    {
        this.Owner = owner;
        this.Pin = pin;
    }
}

public static func Main() -> void
{
    account: Account = new Account("alice", 1234);

    text: string = JsonSerializer.Serialize<Account>(account);
    println(text);   // {"Owner":"alice"}

    // If Pin must round-trip, expose it as a public field or serialize a separate DTO.
}`}
