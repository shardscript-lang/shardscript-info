<H2>Summary</H2>

<Prose>
  <InlineCode>StreamReader</InlineCode> and <InlineCode>StreamWriter</InlineCode> are text-oriented
  adapters in the <InlineCode>io</InlineCode> namespace. They decode UTF-8 from an{' '}
  <InlineCode>IReadableStream</InlineCode> and encode UTF-8 to an <InlineCode>IWritableStream</InlineCode>,
  exposing line-based and whole-stream text operations. Both implement <InlineCode>IDisposable</InlineCode>;
  disposing the wrapper also disposes the underlying stream.
</Prose>

<H2>Syntax</H2>

<Prose>
  Both classes are instantiated with a single constructor argument. The wrapper stores the stream
  reference internally and tracks its own disposed state.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">RuntimeException — Invalid UTF-8 sequence</strong>{' '}
    <InlineCode>StreamReader.Read()</InlineCode> throws when the leading byte or its continuation
    bytes do not form a valid UTF-8 codepoint.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">RuntimeException — Cannot access a disposed StreamReader</strong>{' '}
    Any call after <InlineCode>Close()</InlineCode> or <InlineCode>Dispose()</InlineCode> fails.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">RuntimeException — Cannot access a disposed StreamWriter</strong>{' '}
    Any call after <InlineCode>Close()</InlineCode> or <InlineCode>Dispose()</InlineCode> fails.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">RuntimeException — Stream does not support Read / Write</strong>{' '}
    Thrown by the underlying byte stream if the wrapped object does not implement the expected
    interface method.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">RuntimeException — Cannot access a closed stream</strong>{' '}
    Operations on a closed underlying stream (for example, a disposed <InlineCode>MemoryStream</InlineCode>)
    fail before the reader or writer can buffer data.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>UTF-8 only.</strong> The current implementation hard-codes UTF-8. There is no constructor
  overload for selecting <InlineCode>Encoding.ASCII</InlineCode>, <InlineCode>Encoding.UTF8</InlineCode>,
  or other encodings. Strings are converted through the runtime's wide-character/UTF-8 helpers before
  being written or after being read.
</Prose>

<Prose>
  <strong>Newline handling.</strong> <InlineCode>WriteLine</InlineCode> always appends a single{' '}
  <InlineCode>\n</InlineCode> byte (0x0A), regardless of platform. <InlineCode>ReadLine</InlineCode>{' '}
  stops at the first <InlineCode>\n</InlineCode> it encounters and does not include it in the result.
  If a source uses <InlineCode>\r\n</InlineCode> line endings, the carriage return remains at the end
  of the returned string unless you trim it yourself.
</Prose>

<Prose>
  <strong>EOF conventions.</strong> <InlineCode>ReadLine</InlineCode> returns an empty string at EOF.
  Because an empty string is also a valid line value, the standard idiom is to call it repeatedly
  until the returned length is zero. <InlineCode>Read()</InlineCode> returns -1 at EOF, and{' '}
  <InlineCode>ReadToEnd()</InlineCode> returns an empty string when no bytes remain.
</Prose>

<Prose>
  <strong>Dispose cascades.</strong> <InlineCode>Close()</InlineCode> and{' '}
  <InlineCode>Dispose()</InlineCode> are aliases for the same implementation on both classes. They
  flush the writer, call <InlineCode>Dispose()</InlineCode> on the underlying stream, and then set
  the wrapper's internal disposed flag. After disposal, both the wrapper and the wrapped stream are
  unusable.
</Prose>

<Prose>
  <strong>Buffering.</strong> <InlineCode>StreamWriter</InlineCode> does not maintain a separate
  character buffer; it encodes each string and forwards the bytes immediately.{' '}
  <InlineCode>StreamReader.Read()</InlineCode> allocates a temporary four-byte array to decode a
  complete codepoint. <InlineCode>ReadLine</InlineCode> and <InlineCode>ReadToEnd</InlineCode> accumulate
  bytes in native vectors and perform a single UTF-8 to wide-string conversion at the end.
</Prose>

<Callout tone="amber" title="Async wrappers not implemented">
  <InlineCode>StreamReader</InlineCode> and <InlineCode>StreamWriter</InlineCode> do not expose async
  members such as <InlineCode>ReadLineAsync</InlineCode> or <InlineCode>WriteLineAsync</InlineCode>.
  If you need async I/O, use the <InlineCode>ReadAsync</InlineCode> / <InlineCode>WriteAsync</InlineCode>{' '}
  methods on the underlying stream directly, or run the synchronous reader/writer methods inside an
  async method.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Line-oriented read and write over MemoryStream.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using io;

namespace demo;

public static func Main() -> void
{
    ms: MemoryStream = new MemoryStream();

    writer: StreamWriter = new StreamWriter(ms);
    writer.WriteLine("hello");
    writer.WriteLine("world");
    writer.Flush();

    // Rewind before reading; writing leaves the position at the end.
    ms.Position = 0;

    reader: StreamReader = new StreamReader(ms);
    line1: string = reader.ReadLine();
    line2: string = reader.ReadLine();
    eof: string = reader.ReadLine();

    println(line1);   // hello
    println(line2);   // world
    println(eof);     // ""  (empty string means EOF)

    reader.Dispose();
    writer.Dispose();
}`}

using io;
using filesystem;
using async;

namespace demo;

public static async func CountLines(path: string) -> Task
{
    fs: FileStream = new FileStream(path, FileMode.Open, FileAccess.Read);
    defer fs.Dispose();

    reader: StreamReader = new StreamReader(fs);
    defer reader.Dispose();

    count: int = 0;
    while (true)
    {
        line: string = reader.ReadLine();
        if (line == "")
        {
            break;
        }

        count = count + 1;
    }

    println("total lines: " + count);
}

public static func Main() -> void

    Task.Wait(task);

<Prose>
  <strong>Common mistakes and edge cases.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using io;

namespace demo;

public static func Main() -> void
{
    // Mistake 1: Forgetting to rewind the MemoryStream before reading.
    ms: MemoryStream = new MemoryStream();
    writer: StreamWriter = new StreamWriter(ms);
    writer.WriteLine("data");
    writer.Flush();

    // ms.Position is still at the end; ReadLine returns "" immediately.
    readerAtEnd: StreamReader = new StreamReader(ms);
    empty: string = readerAtEnd.ReadLine();
    println("at end: '" + empty + "'");   // at end: ''
    readerAtEnd.Dispose();

    // Correct: rewind first.
    ms.Position = 0;
    reader: StreamReader = new StreamReader(ms);
    line: string = reader.ReadLine();
    println("rewound: '" + line + "'");   // rewound: 'data'
    reader.Dispose();

    // Mistake 2: Using a reader after disposing it.
    ms2: MemoryStream = new MemoryStream();
    reader2: StreamReader = new StreamReader(ms2);
    reader2.Dispose();

    // This would throw: Cannot access a disposed StreamReader.
    // reader2.ReadLine();

    // Mistake 3: Expecting ReadLine to strip \\r from \\r\\n files.
    ms3: MemoryStream = new MemoryStream();
    writer3: StreamWriter = new StreamWriter(ms3);
    writer3.Write("windows\\r\\n");   // simulate a CRLF source
    writer3.Flush();
    ms3.Position = 0;

    reader3: StreamReader = new StreamReader(ms3);
    crlfLine: string = reader3.ReadLine();
    println("last char code: " + crlfLine[crlfLine.Length - 1]);   // 13 ('\\r')
    reader3.Dispose();

    writer.Dispose();
    writer3.Dispose();
}`}

  filename="stream_reader_writer_edge_cases.shard"
