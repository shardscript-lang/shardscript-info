<H2>Summary</H2>

<Prose>
  <InlineCode>MemoryStream</InlineCode> is a byte-array-backed in-memory stream that implements{' '}
  <InlineCode>IReadableStream</InlineCode>, <InlineCode>IWritableStream</InlineCode>, and{' '}
  <InlineCode>IDisposable</InlineCode>. All data lives in a ShardScript <InlineCode>byte[]</InlineCode>{' '}
  managed by the stream itself. It can be created empty, with a pre-allocated capacity, or from an
  existing byte array (which produces a read-only view). Capacity grows automatically on writes,
  and the full contents can be extracted as a new array via <InlineCode>ToArray</InlineCode>.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Closed stream</strong> — Any read, write, seek, length
    change, capacity change, <InlineCode>ToArray</InlineCode>, or <InlineCode>GetBuffer</InlineCode>{' '}
    after <InlineCode>Close</InlineCode>/<InlineCode>Dispose</InlineCode> throws.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Write to read-only stream</strong> — Calling{' '}
    <InlineCode>Write</InlineCode>, <InlineCode>WriteAsync</InlineCode>,{' '}
    <InlineCode>SetLength</InlineCode>, or setting <InlineCode>Capacity</InlineCode> on a stream
    created with <InlineCode>new MemoryStream(buffer)</InlineCode> throws.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Negative arguments</strong> — Negative{' '}
    <InlineCode>offset</InlineCode>, <InlineCode>count</InlineCode>, <InlineCode>capacity</InlineCode>,{' '}
    <InlineCode>Position</InlineCode>, <InlineCode>Length</InlineCode>, or{' '}
    <InlineCode>Capacity</InlineCode> values throw.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Invalid seek origin</strong> — Passing a{' '}
    <InlineCode>SeekOrigin</InlineCode> other than <InlineCode>Begin</InlineCode>,{' '}
    <InlineCode>Current</InlineCode>, or <InlineCode>End</InlineCode> throws.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Seek before start</strong> — A seek that results in a
    negative Position throws.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Capacity too small</strong> — Setting{' '}
    <InlineCode>Capacity</InlineCode> to a value less than the current <InlineCode>Length</InlineCode>{' '}
    throws.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Canceled async operation</strong> — The cancellation-token
    overloads of <InlineCode>ReadAsync</InlineCode>, <InlineCode>WriteAsync</InlineCode>, and{' '}
    <InlineCode>FlushAsync</InlineCode> return a faulted task with an operation-canceled exception
    when the token is already canceled.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Destination buffer too small for read</strong> —{" "}
    <InlineCode>Read</InlineCode> throws when <InlineCode>buffer.Length</InlineCode> is less than{" "}
    <InlineCode>offset + count</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Source buffer too small for write</strong> —{" "}
    <InlineCode>Write</InlineCode> throws when the source <InlineCode>buffer.Length</InlineCode> is less
    than <InlineCode>offset + count</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Internal buffer too small</strong> — This is a defensive
    error that should not occur in normal use. It indicates that the internal buffer was not grown
    sufficiently before the read or write loop began.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>Interface hierarchy.</strong> <InlineCode>MemoryStream</InlineCode> implements{' '}
  <InlineCode>io.IReadableStream</InlineCode>, <InlineCode>io.IWritableStream</InlineCode>, and{' '}
  <InlineCode>IDisposable</InlineCode>. This lets you pass a <InlineCode>MemoryStream</InlineCode> to
  any API that consumes the interfaces, such as <InlineCode>StreamReader</InlineCode>,{' '}
  <InlineCode>StreamWriter</InlineCode>, <InlineCode>BinaryReader</InlineCode>, or{' '}
  <InlineCode>BinaryWriter</InlineCode>.
</Prose>

<Prose>
  <strong>Capacity growth.</strong> When a write would exceed the current buffer, the runtime calls{' '}
  <InlineCode>EnsureCapacity</InlineCode>. The new size is{' '}
  <InlineCode>max(required, capacity * 2)</InlineCode>, with a floor of 256 bytes. A new{' '}
  <InlineCode>byte[]</InlineCode> is allocated, the existing contents are copied element by element,
  and the internal <InlineCode>_buffer</InlineCode> field is replaced. The old array becomes eligible
  for garbage collection when no other references remain.
</Prose>

<Prose>
  <strong>Read-only construction.</strong> <InlineCode>new MemoryStream(buffer)</InlineCode> wraps the
  array without copying it. The stream starts at Position 0, Length equals{' '}
  <InlineCode>buffer.Length</InlineCode>, and the internal writable flag is false. Reading advances
  Position normally, but writes are rejected. Closing or disposing the stream does not free the
  caller's original array.
</Prose>

<Prose>
  <strong>Position versus Length.</strong> <InlineCode>Position</InlineCode> can be set to any
  non-negative value, including values larger than <InlineCode>Length</InlineCode>. A subsequent{' '}
  <InlineCode>Write</InlineCode> at such a position will grow <InlineCode>Length</InlineCode> to{' '}
  <InlineCode>Position + count</InlineCode>. The gap between the old Length and the new write offset
  is filled with zeros because fresh buffers are zero-initialized.
</Prose>

<Prose>
  <strong>GetBuffer versus ToArray.</strong> <InlineCode>GetBuffer</InlineCode> returns the live
  internal buffer, which may be larger than <InlineCode>Length</InlineCode>. Mutating it changes the
  stream's data directly. <InlineCode>ToArray</InlineCode> always allocates a new array of exactly{' '}
  <InlineCode>Length</InlineCode> bytes and copies the logical contents.
</Prose>

<Callout tone="blue">
  The async methods are not truly asynchronous for <InlineCode>MemoryStream</InlineCode>. They exist
  so the class can satisfy <InlineCode>IReadableStream</InlineCode> and{' '}
  <InlineCode>IWritableStream</InlineCode> contracts; under the hood they call the synchronous{' '}
  <InlineCode>Read</InlineCode>, <InlineCode>Write</InlineCode>, or <InlineCode>Flush</InlineCode> and
  return a completed task.
</Callout>

<Callout tone="amber" title="CanWrite not exposed">
  <InlineCode>MemoryStream</InlineCode> tracks writability internally, but it does not currently
  expose a public <InlineCode>CanWrite</InlineCode> property. Determine writability from the
  constructor used: streams created with <InlineCode>init()</InlineCode> or{' '}
  <InlineCode>init(capacity: int)</InlineCode> are writable; streams created with{' '}
  <InlineCode>init(buffer: byte[])</InlineCode> are read-only.
</Callout>

<H2>Examples</H2>

<Prose>
  <strong>Basic write, read back, and snapshot.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using io;

namespace demo;

public static func Main() -> void
{
    ms: MemoryStream = new MemoryStream();
    defer ms.Dispose();

    payload: byte[] = [72 as byte, 101 as byte, 108 as byte, 108 as byte, 111 as byte];
    ms.Write(payload, 0, payload.Length);

    println(ms.Length);     // 5
    println(ms.Position);   // 5

    ms.Position = 0;
    buffer: byte[] = [0 as byte; 5];
    read: int = ms.Read(buffer, 0, buffer.Length);

    println(read);          // 5
    println(buffer[0]);     // 72

    snapshot: byte[] = ms.ToArray();
    println(snapshot.Length); // 5
}`}

<Prose>
  <strong>Capacity growth and explicit pre-allocation.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using io;

namespace demo;

public static func Main() -> void
{
    ms: MemoryStream = new MemoryStream();
    defer ms.Dispose();

    println(ms.Capacity);  // 0

    ms.Write([1 as byte], 0, 1);
    println(ms.Capacity);  // 256 (minimum growth floor)

    chunk: byte[] = [0 as byte; 300];
    ms.Write(chunk, 0, chunk.Length);
    println(ms.Capacity);  // 512 (doubled from 256 to satisfy required 301)
    println(ms.Length);    // 301

    // Pre-allocate room for a known payload size.
    ms.Capacity = 1024;
    println(ms.Capacity);  // 1024
    println(ms.Length);    // still 301
}`}

<Prose>
  <strong>Common mistakes to avoid.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using io;

namespace demo;

public static func Main() -> void
{
    // Mistake 1: Forgetting that new MemoryStream(buffer) is read-only.
    data: byte[] = [1 as byte, 2 as byte];
    ro: MemoryStream = new MemoryStream(data);
    defer ro.Dispose();
    // ro.Write([3 as byte], 0, 1); // throws: cannot write to non-writable stream

    // Mistake 2: Accessing the stream after Dispose.
    ms: MemoryStream = new MemoryStream();
    ms.Dispose();
    // ms.Length; // throws: cannot access a closed stream

    // Mistake 3: Setting Capacity below Length.
    ms2: MemoryStream = new MemoryStream();
    defer ms2.Dispose();
    ms2.Write([1 as byte, 2 as byte, 3 as byte], 0, 3);
    // ms2.Capacity = 1; // throws: capacity cannot be less than length

    // Mistake 4: Passing an invalid SeekOrigin value.
    ms3: MemoryStream = new MemoryStream();
    defer ms3.Dispose();
    ms3.Write([1 as byte, 2 as byte], 0, 2);
    // ms3.Seek(0, 99 as SeekOrigin); // throws: invalid seek origin

    // Mistake 5: Passing a destination buffer that is smaller than offset + count.
    ms4: MemoryStream = new MemoryStream();
    defer ms4.Dispose();
    ms4.Write([1 as byte, 2 as byte, 3 as byte], 0, 3);
    ms4.Position = 0;
    // small: byte[] = [0 as byte; 2];
    // ms4.Read(small, 0, 3); // throws: destination buffer is too small
}`}
