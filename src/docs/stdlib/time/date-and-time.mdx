<H2>Summary</H2>

<Prose>
  The <InlineCode>shard.time</InlineCode> library provides two value types in the <InlineCode>time</InlineCode>{' '}
  namespace: <InlineCode>TimeSpan</InlineCode> for representing a duration, and{' '}
  <InlineCode>DateTime</InlineCode> for representing an instant in time. Both are implemented as native structs,
  store their data as 64-bit tick counts, and expose factory methods, properties, arithmetic operators, and
  formatting helpers.
</Prose>

<H2>Syntax</H2>

<Prose>
  Reference the <InlineCode>time</InlineCode> namespace with a <InlineCode>using</InlineCode> directive. The
  library is loaded automatically when a <InlineCode>using time;</InlineCode> directive is present, or it can
  be passed to the interpreter with the <InlineCode>-l</InlineCode> flag when running standalone scripts.
</Prose>

<CodeBlock
  code={`using stdio;
using time;

namespace demo;

public static func Main() -> void
{
    span: TimeSpan = TimeSpan.FromSeconds(90.0);
    println(span.TotalMinutes);

    now: DateTime = DateTime.Now;
    println(now.ToString("yyyy-MM-dd HH:mm:ss"));
}`}

<H2>Struct DateTime</H2>

<Prose>
  <InlineCode>DateTime</InlineCode> stores an instant as a 64-bit tick count together with a{' '}
  <InlineCode>DateTimeKind</InlineCode>. One tick is 100 nanoseconds. The epoch for Unix conversions is
  1970-01-01 00:00:00 UTC.
</Prose>

<H2>Returns</H2>

<Prose>
  Factory methods and operators return new <InlineCode>TimeSpan</InlineCode> or{' '}
  <InlineCode>DateTime</InlineCode> value-type instances. Properties return the corresponding primitive or
  enum value. Methods that perform arithmetic return a new instance and do not mutate the receiver.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Division by zero.</strong> Dividing a{' '}
    <InlineCode>TimeSpan</InlineCode> by <InlineCode>0.0</InlineCode> or dividing two spans where the divisor
    is zero throws a runtime exception.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Invalid Unix timestamp.</strong> Very large positive or negative
    Unix timestamps can produce a <InlineCode>DateTime</InlineCode> outside the range supported by the
    platform <InlineCode>time_t</InlineCode> conversion.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Local-time ambiguity.</strong>{' '}
    <InlineCode>ToLocalTime</InlineCode> and <InlineCode>ToUniversalTime</InlineCode> rely on the host
    platform's local-time zone database. On hosts without valid zone data, the conversion may return the
    original ticks unchanged.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <InlineCode>TimeSpan</InlineCode> and <InlineCode>DateTime</InlineCode> are registered as native structs, not
  classes, so they are value types inside ShardScript. Assignment and parameter passing copy the underlying
  tick fields rather than sharing a reference. Both types are immutable: every mutating-looking operation such
  as <InlineCode>Add</InlineCode> or <InlineCode>Negate</InlineCode> returns a new instance.
</Prose>

<Prose>
  The internal representation uses the same tick scale as .NET: 1 tick = 100 nanoseconds, 10 000 ticks = 1
  millisecond, and 10 000 000 ticks = 1 second. This makes conversions to and from Unix timestamps
  straightforward and avoids floating-point drift for whole-second values.
</Prose>

<Prose>
  The custom format string for <InlineCode>DateTime.ToString(format)</InlineCode> supports the following
  tokens. All other characters are copied to the output literally.
</Prose>

<H2>Examples</H2>

<Prose>
  Create durations, perform arithmetic, and format the current local time.
</Prose>

<CodeBlock
  code={`using stdio;
using time;

namespace demo;

public static func Main() -> void
{
    span: TimeSpan = TimeSpan.FromSeconds(90.0);
    println("TotalSeconds = " + span.TotalSeconds);
    println("Minutes = " + span.Minutes);
    println("Seconds = " + span.Seconds);

    a: TimeSpan = TimeSpan.FromMinutes(10.0);
    b: TimeSpan = TimeSpan.FromMinutes(5.0);
    println("10min + 5min = " + (a + b).TotalMinutes + " min");

    scaled: TimeSpan = a * 2.0;
    println("10min * 2 = " + scaled.TotalMinutes + " min");

    now: DateTime = DateTime.Now;
    println("Now: " + now.ToString("yyyy-MM-dd HH:mm:ss"));

    tomorrow: DateTime = now + TimeSpan.FromDays(1.0);
    println("Tomorrow day: " + tomorrow.Day);

    utc: DateTime = now.ToUniversalTime();
    println("UTC year: " + utc.Year);
}`}
  language="csharp"
  filename="time_demo.shard"
/>
