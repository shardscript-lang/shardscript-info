<H2>Summary</H2>

<Prose>
  The <InlineCode>shard.socket</InlineCode> library exposes the <InlineCode>Socket</InlineCode> and{' '}
  <InlineCode>SocketStream</InlineCode> classes in the <InlineCode>net</InlineCode> namespace for IPv4 TCP
  networking. <InlineCode>Socket</InlineCode> provides low-level connect, listen, accept, and string-oriented
  send/receive operations, while <InlineCode>SocketStream</InlineCode> wraps a connected socket in the{' '}
  <InlineCode>io</InlineCode> stream interfaces for byte-oriented asynchronous I/O.
</Prose>

<H2>Syntax</H2>

<Prose>
  Import the namespace with <InlineCode>using net;</InlineCode>. Both classes are reference types that implement{' '}
  <InlineCode>IDisposable</InlineCode> and should be disposed after use.
</Prose>

<H2>Exceptions / Errors</H2>

<ul className="space-y-2 text-text-secondary">
  <Bullet>
    <strong className="text-text-primary">Namespace import required</strong> — The{' '}
    <InlineCode>net</InlineCode> namespace must be imported with <InlineCode>using net;</InlineCode> before
    referencing <InlineCode>Socket</InlineCode> or <InlineCode>SocketStream</InlineCode>.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Socket creation failure</strong> — Constructing{' '}
    <InlineCode>new Socket()</InlineCode> or <InlineCode>new SocketStream()</InlineCode> throws a runtime exception
    when the underlying <InlineCode>socket(AF_INET, SOCK_STREAM, IPPROTO_TCP)</InlineCode> call fails or the network
    subsystem cannot be initialized.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Invalid server socket handle</strong> —{' '}
    <InlineCode>Socket.Accept()</InlineCode> and <InlineCode>Socket.AcceptAsync()</InlineCode> throw when called on a
    socket that has not been bound and listened, or whose handle has already been closed.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Invalid IP address</strong> —{' '}
    <InlineCode>SocketStream.Connect</InlineCode> throws when <InlineCode>ip</InlineCode> cannot be parsed as an IPv4
    address. <InlineCode>Socket.Connect</InlineCode> returns <InlineCode>false</InlineCode> instead.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Receive on invalid socket</strong> —{' '}
    <InlineCode>Socket.Receive</InlineCode> returns an empty string when the handle is invalid or when the peer has
    closed the connection; it does not throw.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Read from a closed SocketStream</strong> —{' '}
    <InlineCode>SocketStream.Read</InlineCode> and <InlineCode>ReadAsync</InlineCode> throw when the stream has been
    disposed or closed.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Negative offset or count</strong> —{' '}
    <InlineCode>SocketStream.Read</InlineCode> and <InlineCode>SocketStream.Write</InlineCode> reject negative{' '}
    <InlineCode>offset</InlineCode> or <InlineCode>count</InlineCode> values.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Socket send/receive failure</strong> —{' '}
    <InlineCode>SocketStream.Write</InlineCode> and <InlineCode>SocketStream.Read</InlineCode> throw when the underlying
    native send or recv call reports an error.
  </Bullet>
  <Bullet>
    <strong className="text-text-primary">Operation canceled</strong> — The cancellation-aware async overloads on
    <InlineCode>SocketStream</InlineCode> fault with an <InlineCode>Operation canceled</InlineCode> error when the
    provided <InlineCode>CancellationToken</InlineCode> is canceled before or during the operation.
  </Bullet>
</ul>

<H2>Remarks</H2>

<Prose>
  <strong>IPv4 TCP only.</strong> The current implementation creates sockets with{' '}
  <InlineCode>AF_INET</InlineCode>, <InlineCode>SOCK_STREAM</InlineCode>, and <InlineCode>IPPROTO_TCP</InlineCode>. IPv6
  addresses, UDP datagrams, and Unix domain sockets are not supported by this library.
</Prose>

<Prose>
  <strong>Wide-character string transport.</strong> <InlineCode>Socket.Send</InlineCode> transmits each character as a
  platform wide character (UTF-16LE on Windows, typically 32-bit on Linux). The byte count returned by{' '}
  <InlineCode>Send</InlineCode> is therefore <InlineCode>data.Length * sizeof(wchar_t)</InlineCode>, not the character
  count. <InlineCode>Receive</InlineCode> reads raw bytes and reconstructs a string from complete wide characters. Use{' '}
  <InlineCode>SocketStream</InlineCode> when you need portable byte-oriented transport and control over encoding.
</Prose>

<Prose>
  <strong>Bind any local interface.</strong> For server sockets, pass <InlineCode>"0.0.0.0"</InlineCode> or an empty
  string to <InlineCode>Bind</InlineCode> to listen on all available IPv4 interfaces. A specific address such as{' '}
  <InlineCode>"127.0.0.1"</InlineCode> restricts the listener to the loopback interface.
</Prose>

<Prose>
  <strong>Backlog behavior.</strong> <InlineCode>Listen(backlog)</InlineCode> forwards the backlog value directly to
  the operating system. A negative value such as <InlineCode>-1</InlineCode> is accepted by the implementation and
  resolved to a platform default, but the exact limit depends on the host OS.
</Prose>

<Prose>
  <strong>SocketStream is a thin stream adapter.</strong> <InlineCode>SocketStream</InlineCode> implements{' '}
  <InlineCode>io.IReadableStream</InlineCode>, <InlineCode>io.IWritableStream</InlineCode>, and{' '}
  <InlineCode>IDisposable</InlineCode>. It does not buffer, seek, or expose <InlineCode>Position</InlineCode> or{' '}
  <InlineCode>Length</InlineCode>. <InlineCode>Flush</InlineCode> and <InlineCode>FlushAsync</InlineCode> are no-ops
  because TCP sends data immediately.
</Prose>

<Prose>
  <strong>Asynchronous operations run on the thread pool.</strong>{' '}
  <InlineCode>Socket.AcceptAsync</InlineCode> and the <InlineCode>SocketStream</InlineCode> async methods schedule the
  blocking native call on a background thread and resume the awaiting ShardScript task on completion. This keeps the
  VM event loop responsive while waiting for network I/O.
</Prose>

<Prose>
  <strong>End-of-stream detection.</strong> <InlineCode>SocketStream.Read</InlineCode> and{' '}
  <InlineCode>ReadAsync</InlineCode> return <InlineCode>0</InlineCode> when the peer gracefully closes the connection.
  A loop that reads until EOF must treat <InlineCode>0</InlineCode> as termination, not as an error.
</Prose>

<Prose>
  <strong>Dispose is idempotent.</strong> Calling <InlineCode>Close()</InlineCode> or{' '}
  <InlineCode>Dispose()</InlineCode> more than once on a <InlineCode>Socket</InlineCode> or{' '}
  <InlineCode>SocketStream</InlineCode> is safe. Both methods close the native handle and mark the object as closed.
  Because both classes implement <InlineCode>IDisposable</InlineCode>, the <InlineCode>defer</InlineCode> statement can
  be used for deterministic cleanup.
</Prose>

<Callout tone="blue">
  Prefer <InlineCode>SocketStream</InlineCode> for new code. It interoperates with generic helpers written against{' '}
  <InlineCode>io.IReadableStream</InlineCode> and <InlineCode>io.IWritableStream</InlineCode>, supports cancellation
  tokens, and avoids the wide-character encoding quirks of the low-level <InlineCode>Socket.Send</InlineCode> /{' '}
  <InlineCode>Socket.Receive</InlineCode> API.
</Callout>

<Callout tone="amber" title="Not implemented">
  UDP sockets, IPv6, raw sockets, non-blocking polling, socket options (keep-alive, no-delay, receive buffer size),
  and DNS hostname resolution are not exposed by <InlineCode>shard.socket</InlineCode>. Connect by IPv4 address or
  resolve hostnames through a separate library before calling <InlineCode>Connect</InlineCode>.
</Callout>

<Prose>
  <strong>Byte-oriented echo server and client with SocketStream.</strong>
</Prose>

<CodeBlock
  code={`using stdio;
using async;
using net;
using io;

namespace demo;

public class Program
{
    public static async func RunServer(port: int, done: TaskCompletionSource<int>) -> Task
    {
        server: Socket = new Socket();
        defer server.Dispose();

        if (!server.Bind("127.0.0.1", port))
        {
            println("Failed to bind");
            throw new RuntimeException();
        }

        if (!server.Listen(1))
        {
            println("Failed to listen");
            throw new RuntimeException();
        }

        client: Socket = await server.AcceptAsync();
        defer client.Dispose();

        stream: SocketStream = new SocketStream(client);
        defer stream.Dispose();

        buffer: byte[] = [0 as byte; 64];
        read: int = await stream.ReadAsync(buffer, 0, buffer.Length);
        if (read == 0)
        {
            println("Client disconnected before sending data");
            throw new RuntimeException();
        }

        await stream.WriteAsync(buffer, 0, read);
        done.SetResult(0);
    }

    public static async func RunClient(port: int) -> Task
    {
        client: Socket = new Socket();
        defer client.Dispose();

        if (!client.Connect("127.0.0.1", port))
        {
            println("Failed to connect");
            throw new RuntimeException();
        }

        stream: SocketStream = new SocketStream(client);
        defer stream.Dispose();

        payload: byte[] = [72 as byte, 101 as byte, 108 as byte, 108 as byte, 111 as byte];
        await stream.WriteAsync(payload, 0, payload.Length);

        buffer: byte[] = [0 as byte; 64];
        read: int = await stream.ReadAsync(buffer, 0, buffer.Length);

        i: int = 0;
        while (i < read)
        {
            println(buffer[i]);
            i = i + 1;
        }
    }

    public static func Main() -> void
    {
        port: int = 17654;
        done: TaskCompletionSource<int> = new TaskCompletionSource<int>();

        serverTask: Task = RunServer(port, done);

        // Give the server time to start listening before connecting.
        Task.Wait(Task.Delay(50));

        clientTask: Task = RunClient(port);
        Task.Wait(clientTask);
        Task.Wait(serverTask);

        println("echo completed");
    }
}`}
  language="csharp"
  filename="socket_stream_echo.shard"
/>

using io;

namespace demo;

public static func ReadAll(stream: SocketStream) -> byte[]

    accumulator: MemoryStream = new MemoryStream();

    chunk: byte[] = [0 as byte; 256];
